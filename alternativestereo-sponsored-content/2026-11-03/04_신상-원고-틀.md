## 신상마다 미리 모을 것

- [ ] **키워드:** 공식 상세페이지(올리브영·공식몰)에 반복되는 문구 훅 1개 + 제품별 키워드 3개
- [ ] **발색 사진:** 올리브영 옵션별 발색 사진을 옵션 이름과 하나씩 대조해 번호 확인
- [ ] **시딩박스 사진:** 브랜드 촬영본, 또는 촬영자 허락 + 출처 표기
- [ ] **판매처와 가격:** 신상을 실제로 파는 곳만, 작성일에 다시 확인
- [ ] **인스타그램 레퍼런스:** 훅 문장과 구성 디테일만 참고, 게시물·영상은 넣지 않기
