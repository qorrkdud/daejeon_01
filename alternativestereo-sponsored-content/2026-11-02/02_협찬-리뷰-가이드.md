# 협찬 리뷰 가이드 (2026-11-02)

## 브랜드 방향 & 톤앤매너

얼터너티브스테레오의 핵심은 "둥둥 뜨지 않고 내 피부에 녹아드는 감각적인 누드"입니다. 레퍼런스 전반에서 반복된 키워드를 기준으로 정리했습니다.

**핵심 메시지 3가지**

1. **로우톤 누드**: 흰기·노란기 없이 내 스킨톤을 따라 깊어지는 컬러. "바르면 원래 내 혈색이 좋아 보이는" 느낌.
2. **카라멜 쫀득광**: 녹진하고 도톰한 광, 끈적임 없음. 카라멜 글레이즈는 브랜드의 시그니처("얼터 하면 카글").
3. **레이어링**: 가볍게 쓱 바르면 맑고, 겹치면 깊어지는 조절 가능한 발색. 제품끼리 조합해 쓰는 재미.

**무드와 언어**

- 추구미: 어른여자, 배우상, 백화점 립 느낌, 차분하고 그윽한 분위기
- 컬러 묘사는 디저트·음료 언어로: "구운 헤이즐넛 베이지", "바닐라 잼에 말린 장미 한 스푼"
- 자주 쓰는 단어: 멀멀한, 미지근한, 녹진한, 스며드는, MLBB, 톤온톤
- 말투는 친구에게 추천하듯 다정하게, 이모지는 브라운 하트 계열 위주로 절제

**피해야 할 톤**

- "인생템", "무조건 사세요" 같은 과장된 구매 압박
- 쨍한 비비드 톤·화려한 풀메이크업 위주 연출 (브랜드 무드와 어긋남)

## 네이버 블로그 초안 구조

예시 제품: 세컨 스킨 누드 컬렉션 (카라멜 글레이즈 밤 + 수플레이어 아이팔레트). 완성형 원고는 [03_블로그-원고.md](03_블로그-원고.md)에 있습니다.

**제목 예시** (브랜드명 + 컬렉션명 + 검색 키워드)

- 얼터너티브스테레오 세컨 스킨 누드 컬렉션 카라멜 글레이즈 밤 수플레이어 아이팔레트 발색 후기
- 올리브영 신상 얼터너티브스테레오 로우톤 누드립 추천 카라멜꾸덕밤 전컬러 발색

**본문 순서**

1. 광고 표기 (본문 맨 위): #제품제공 #광고
2. 도입: 추구미 공감
3. 컬렉션 컨셉 한 줄: '내 스킨톤을 따라 깊어지는 음영'
4. 제품 ① 카라멜 글레이즈 밤 (21,000원 / 6컬러): #카라멜꾸덕밤 #로우톤누드 #멀티케어밤
5. 컬러별 발색 + 추천 대상 (받은 컬러만)
6. 증정품: 마시멜로우 치크 팟 (미출시)
7. 제품 ② 수플레이어 아이팔레트 (27,000원 / 2컬러): #로우톤누드 #3타입텍스처 #애쉬음영컬러
8. 나만의 메이크업 순서 (필수, 컬러 번호로)
9. 프로모션 안내 (브랜드가 캠페인별로 제공)
10. 마무리 + 경제적 대가 문구 + 해시태그

## 인스타그램/틱톡 숏폼 가이드

숏폼은 첫 2초 훅과 캡션 첫 줄이 성과를 가릅니다. 레퍼런스 릴스와 피드는 모두 '한 줄 정의 + 증정품 + 기간·가격' 순서였습니다.

**릴스·틱톡 컷 구성 (15~30초)**

1. 0~2초 훅: 완성된 로우톤 누드 얼굴 클로즈업 + 자막 "얼터가 말아주는 어른여자 누디"
2. 3~8초: 카라멜 글레이즈 밤을 바르며 광이 차오르는 입술 클로즈업 (쫀득광이 보이게 자연광)
3. 9~15초: 수플레이어 팔레트 오픈 → 매트·쉬머·젤 라이너를 한 컷씩
4. 16~22초: 비포 → 애프터 전환 (손가락 스냅이나 화면 가리기)
5. 마지막 컷: 기획세트 구성과 증정품 + 프로모션 기간 자막

**피드 캐러셀 (6~8장)**: 표지(완성 얼굴) → 컬렉션 누끼 → 립 발색 → 팔레트 발색 → 증정품 → 메이크업 순서 → 프로모션 정보

**캡션 템플릿**

```
#광고 얼터가 말아주는 어른여자 누디 컬렉션🤎
@alternativestereo 세컨 스킨 누드 컬렉션

[내 스킨톤 따라 깊어지는 로우톤 누드, 한 줄 소감]

✔️카라멜 글레이즈 밤: [끈적임 없는 녹진한 광, 사용 소감]
✔️수플레이어 아이팔레트: [매트·쉬머·젤 라이너 구성 소감]

⭐️[프로모션 기간] 올리브영
- 카라멜 글레이즈 밤 [정가 → 할인가] + 마시멜로우 치크 팟 증정
- 수플레이어 아이팔레트 [정가 → 할인가] + 브러쉬 듀오 증정

#얼터너티브스테레오 #카라멜글레이즈밤 #카라멜꾸덕밤 #수플레이어아이팔레트 #로우톤누드
```

- 브랜드 계정 @alternativestereo 태그와 협찬 표시(유료 파트너십 라벨 또는 #광고)를 필수로 넣어 주세요.
- 틱톡도 같은 컷 구성을 쓰되, 브랜디드 콘텐츠 토글을 켜 주세요.

## 필수 기재사항 & 체크리스트

업로드 전 아래 항목을 모두 확인해 주세요. 광고 표기와 화장품 표현 기준은 법적 리스크가 있어 협상 대상이 아닙니다.

**필수**

- [ ] 본문 맨 위(제목 바로 아래)에 #제품제공 또는 #광고 표기
- [ ] 본문 마지막에 경제적 대가 문구 ("브랜드로부터 제품과 원고료를 제공받아 직접 사용 후 작성")
- [ ] 제목에 '얼터너티브스테레오' + 컬렉션명 + 제품명 포함
- [ ] 키워드 해시태그: #얼터너티브스테레오 #제품명 포함 5개 이상
- [ ] 사진 15장 이상: 누끼컷, 텍스처, 팔뚝 발색, 입술·눈 발색, 얼굴 완성컷
- [ ] 발색은 자연광에서, 과한 보정·필터 없이
- [ ] 컬러마다 톤(웜/뉴트럴/쿨)과 추천 대상 한 줄
- [ ] 프로모션 기간·가격은 브랜드가 전달한 값 그대로
- [ ] 올리브영 제품 링크 삽입

**쓰지 말아야 할 표현**

| 피할 표현 | 대신 |
| --- | --- |
| 주름이 사라져요, 각질이 없어져요 | 주름개선 기능성 제품이에요, 촉촉하게 정돈돼요 |
| 완벽 커버, 절대 안 지워져요 | 제가 써본 바로는 [시간] 동안 유지됐어요 |
| 모든 피부에 어울려요, 부작용 없어요 | 제 피부톤([톤])에는 이렇게 보였어요 |
| 타 브랜드 비교·비방 | 얼터 제품끼리 조합·비교 |
| 품절 확정, 안 사면 손해 | 기획세트로 증정품까지 챙기기 좋아요 |

**일정**: 초안 검수 [날짜] → 최종 업로드 [프로모션 시작일 전후] → 게시 후 최소 [기간] 유지. 모든 게시물은 업로드 전 브랜드 검수를 거쳐 주세요.
