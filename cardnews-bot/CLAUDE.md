# CLAUDE.md — 우리 가게 운영 수칙

Claude가 이 폴더에서 일할 때 가장 먼저 읽는 파일입니다.
아래 내용은 언제든 바꿀 수 있어요. `[ ]` 표시는 아직 정하지 않은 부분입니다.

---

## 1. 계정 컨셉

- **한 줄 소개**: 이번 주 올영 신상, 레시피로 쉽게 풀어드려요
- **다루는 주제**: 세안 같은 뷰티 루틴, 올리브영 제품 사용법을 요리 레시피처럼 쉽게 알려 주기
- **계정 이름**: `@weekly.beauty.recipe` (2026-11-05 사용자가 확정)
  - 아이디에 `oliveyoung`, `올영`은 넣지 않습니다 (공식 계정처럼 보일 수 있음)
- **닉네임(프로필 이름)**: `뷰티 레시피 | 세안·올영템 사용법`
- **핵심 아이디어**: 신상 화장품 하나를 **요리 레시피처럼** 소개합니다.
  - 🥕 **재료** → 주요 성분, 용량, 가격
  - 🍳 **조리법** → 사용 순서와 방법
  - 😋 **맛 포인트** → 제형, 향, 사용감 (출처에 나온 내용만)
  - 🙋 **이런 분께 추천** → 피부 타입, 고민, 상황
- **발행 주기**: 주 1회 (그 주의 신상 모아 보기)

## 2. 타깃

- **20~30대 뷰티 초보** (사용자가 확정)
- 올리브영에서 자주 쇼핑하는 사람
- 신상이 궁금하지만 **정보를 하나하나 찾아볼 시간은 없는 사람**
- 성분 이름이 어렵게 느껴지는 **뷰티 초보**도 이해할 수 있게 씁니다

## 3. 말투

- 친근한 존댓말, **"~해요" 체** (예: "이번 주엔 선크림이 세 개나 나왔어요")
- 짧은 문장. 카드 한 장에 **3~4줄** 정도
- 어려운 성분 이름은 쉬운 말로 풀어 줍니다 (예: "나이아신아마이드 = 톤 정리에 자주 쓰는 성분")
- 이모지는 카드 한 장에 1~2개
- 과장 금지: "인생템", "무조건 사세요" 같은 단정 표현은 쓰지 않습니다

## 4. 금지 사항 (꼭 지키기)

### ① 뉴스·자료 문장을 그대로 복사하지 않기
- `sources/`의 기사나 보도자료 문장을 **그대로 옮기지 않습니다.**
- 내용을 이해한 다음 **우리 말투로 새로 씁니다.**
- 제품명, 성분명, 가격처럼 바꿀 수 없는 사실 정보만 그대로 씁니다.

### ② 출처 표기 필수
- 모든 카드뉴스의 **마지막 카드에 출처**를 적습니다.
- 형식: `출처: 매체(또는 사이트)명, 자료 제목, 날짜`
- 출처가 없는 정보는 카드에 넣지 않습니다.

### ③ 모르는 사실은 지어내지 않기
- 자료에 없는 가격, 성분, 효과, 출시일, 사용 후기를 **추측해서 쓰지 않습니다.**
- 확인이 안 되는 부분은 `[확인 필요]`라고 표시하고 사용자에게 물어봅니다.
- 직접 써 보지 않은 제품은 "써 보니 좋았다"처럼 쓰지 않습니다.

### ④ 그 밖에 조심할 것 (Claude가 추가 제안한 항목)
- 화장품을 **약처럼 표현하지 않기** (예: "여드름 치료", "주름 제거" ✗). 자료에 나온 표현 안에서만 씁니다.
- 가격과 할인 정보는 **자료 날짜 기준**이라고 함께 적습니다 (예: "11월 5일 기준").
- 협찬이나 광고를 받은 콘텐츠라면 **첫 카드에 `#광고` 표시**를 합니다.

## 5. 소식 선별 기준 (candidates → picks 채점표)

후보마다 아래 5가지를 **1~5점**으로 매겨 합계가 높은 순으로 고릅니다 (만점 25점).

| 기준 | 높은 점수를 받는 경우 |
|---|---|
| ① 타깃의 관심도 | 20~30대 뷰티 초보가 궁금해할 주제 (세안, 루틴, 올리브영, 신상, 사용법). 실적·주가·인수 같은 업계 뉴스는 낮게 |
| ② 한 장으로 요약 가능 | 핵심이 하나라서 짧게 정리할 수 있음 |
| ③ 이미지로 표현하기 쉬움 | 제품, 제형, 사용 순서처럼 그림으로 보여 주기 쉬움 |
| ④ 사실 확인이 쉬움 | 공식 발표나 상품 정보로 확인할 수 있음. "~할 전망", "알려졌다"는 낮게 |
| ⑤ 오늘 올려도 시의성 있음 | 최근에 올라온 글이고, 신상·출시처럼 지금 이야기할 이유가 있음 |

- 카드 디자인은 `templates/design_rules.md`를 따릅니다.
- 매일 아침 `morning.bat`를 더블클릭하면 수집, 채점, 추천이 한 번에 실행됩니다.
- `make.bat`를 더블클릭하면 후보 번호 선택 → 원문 보관 → cards.json 확인 → 이미지 6장 → output 폴더 열기 순서로 진행됩니다.
  - cards.json 문구는 Claude가 원문을 읽고 새로 씁니다. cards.json의 `source.link`가 고른 소식의 링크와 같아야 이미지 단계로 넘어갑니다.
  - 2단계에서 기사 속 대표 사진(보통 제품 사진)을 `assets/products/날짜_pick번호.jpg`로 자동 저장합니다. 사진 출처는 원문 보관 파일 맨 위에 적힙니다.
  - 디자인 방식: **HTML(레시피 카드 + 제품 사진, 기본)** / A(크림 레시피 카드) / B(배경 그림) / coverB(표지만 B). 기본값은 make.bat의 `DEFAULT_MODE`에서 바꿉니다.
- **레시피 카드(HTML) 만드는 규칙** (`templates/make_html_cards.py`, 디자인은 `templates/recipe_html/style.css`)
  - 이야기 순서: **고민 → 해결 재료 → 원리 → 언제·어떻게 쓰나 → 정리**. 제품 설명만 늘어놓지 않습니다.
  - cards.json의 `photo.file`에 제품 사진 경로를, `photo.credit`에 사진 출처를 적습니다. 사진이 들어간 카드에는 사진 출처가 자동으로 붙습니다.
  - 카드마다 `layout`(cover / checklist / list / flow / compare / recap / text)과 꾸밈 칸을 적습니다. 예시는 지금의 `cards.json`을 참고합니다.
  - 사용 순서·양처럼 **공식 자료에 없는 사용법은 쓰지 않고**, "제품 상세 페이지에서 확인"으로 안내합니다.
- 자동 채점(`scripts/morning.py`)은 **키워드로 매긴 1차 점수**일 뿐입니다. 최종 선택은 사용자가 합니다.
- 카드에 쓴 소식의 링크는 `used.txt`에 기록하고, 다음 날부터는 후보에서 뺍니다.
- 링크가 달라도 **최근 7일 안에 추천했던 소식과 제목이 많이 겹치면** 추천에서 뺍니다 (같은 제품을 다른 매체가 쓴 경우). 뺀 글은 picks 파일 맨 위에 적힙니다.
- 채점 단어 목록은 `scripts/morning.py`의 `TARGET_KW`(관심 주제), `VISUAL_KW`(이미지로 보여 주기 쉬운 글), `INDUSTRY_KW`(업계 뉴스, 감점)입니다. 놓친 주제가 있으면 여기에 단어를 더합니다.

## 6. 폴더와 작업 흐름 (식당 비유)

```
sources → candidates → picks → (templates + assets) → output
식재료 창고 → 손질대 → 메뉴 확정 → (레시피북 + 양념으로 조리) → 서빙
```

| 폴더 | 하는 일 |
|---|---|
| `sources/` | 모아 온 원본 자료 (기사, 보도자료, 상품 페이지 링크) |
| `candidates/` | 자료에서 뽑은 카드뉴스 후보 아이디어 |
| `picks/` | 사용자가 고른 이번 주 확정본 |
| `templates/` | 카드 디자인 틀 |
| `assets/` | 글꼴, 로고, 아이콘, 배경 이미지 |
| `output/` | 완성된 카드뉴스 이미지 |

- **candidates → picks로 옮기는 결정은 사용자가 합니다.** Claude는 고르지 않고 제안만 합니다.
- `sources/` 안의 원본 자료는 고치거나 지우지 않습니다.

## 7. 사용자에 대해

- 코딩을 처음 해 보는 **윈도우 사용자**입니다.
- 설명은 쉬운 말로, **한 번에 한 단계씩** 진행합니다.
- 파일을 지우거나 밖으로 내보내는 일은 먼저 물어봅니다.
