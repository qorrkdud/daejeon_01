# 카드뉴스 디자인 규칙 (1080 × 1350)

기준: "세안 레시피 시리즈" 카드뉴스(HEALING RECIPE Vol.1·2)의 느낌과 컨셉
분위기: 손글씨 레시피 카드처럼 따뜻한 주방 감성 (크림색 종이 + 진갈색 잉크 + 복숭아·버터 포인트)

## 1. 색 (HEX)

| 역할 | 이름 | HEX | 어디에 쓰나요 |
|---|---|---|---|
| 메인 색 | 테라코타 | `#C9735A` | 영어 라벨(STEP 1, WHY?), 큰 숫자, 강조 태그 |
| 보조 색 1 | 피치 | `#F8D3C0` | 형광펜 밑줄, 표지 배경, 동그란 장식 |
| 보조 색 2 | 버터 | `#FFEBB0` | 강조 카드 배경, 어두운 카드 위 강조 글자 |
| 배경 색 | 크림 | `#FFF8EF` | 모든 카드 기본 바탕 (상자 안쪽은 `#FFFDF9`) |
| 글자 색 | 진갈색 | `#3B2A24` | 제목·본문·상자 테두리 (마무리 카드는 이 색을 배경으로 반전) |
| (보조 글자) | 웜그레이 | `#8A766C` | 출처, 계정명, 설명 글 |

## 2. 글자 크기·여백·위치

| 항목 | 값 | 비고 |
|---|---|---|
| 표지 제목 | **100px**, 가장 굵게, 줄간격 1.14 | 3줄 이내 |
| 본문 카드 제목 | **64~72px**, 굵게, 줄간격 1.22 | 2줄 이내 |
| 본문 글자 | **32~36px**, 줄간격 1.45~1.55 | 한 장에 3~4줄 |
| 상단 라벨 (영어) | 26~28px, 메인 색 | 예: `STEP 1`, `MISTAKE 01` |
| 출처 글자 | 21px, 보조 글자 색 | 카드 맨 아래 |
| 바깥 여백 | **위 84px · 좌우 84px · 아래 76px** | 글자가 이 안쪽에만 오게 |
| 상자 | 테두리 2.5px 진갈색, 모서리 둥글기 24~28px, 안쪽 여백 30~36px | 상자 사이 간격 20px |
| 구분선 | 2px 점선 `#EADBCF` | 상단 바 아래, 목록 사이 |
| **하단 계정명** | **왼쪽 아래**, 22px, 보조 글자 색 | 아래 여백 76px 위에 붙임. 오른쪽 아래는 페이지 번호 |

## 3. 폰트 (윈도우 기본 폰트)

| 용도 | 추천 폰트 | 이유 |
|---|---|---|
| 한글 제목·본문 | **맑은 고딕** (Bold / 보통 / Semilight) | 윈도우 기본 폰트 중 화면에서 가장 또렷하고, 굵기가 3가지라 제목과 본문을 구분하기 좋아요 |
| 영어 라벨·숫자 | **Consolas** (Bold) | 원래 카드의 타자기 글씨 느낌과 가장 비슷한 기본 폰트예요 |

- 원래 카드는 Noto Sans KR(가장 굵은 900)을 써요. 맑은 고딕 Bold는 그보다 조금 얇아서, 표지 제목의 묵직한 느낌은 약간 줄어들어요.
- 이 PC에는 KoPub돋움, 한컴 산뜻돋움도 있어요. 하지만 한컴오피스 같은 프로그램을 설치할 때 함께 들어온 폰트로 보여요(확인 필요). 다른 PC에는 없을 수 있어요.

## 4. 카드 구성 (참고)

- 표지 → 본문 → 마무리(진갈색 배경에 체크리스트, 출처, 다음 편 예고) 순서
- 계정명: `@weekly.beauty.recipe` (확정)
