# 인스타그램 올리기 안내 — 피부가 당기고 예민한 날? (에이피 뷰티 크림 미스트)

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `01.png` ~ `07.png` | 카드 7장 (1080×1350, 세로 4:5) |
| `caption.txt` | 캡션 — 그대로 복사해서 붙여넣기 |

카드 순서: 01 표지 → 02 고민 체크 → 03 해결 재료 → 04 원리 → 05 이렇게 뿌려요 → 06 언제 쓰나요 → 07 정리

## 올리기 전 확인

- [ ] **사진 출처**: 제품 사진은 아모레퍼시픽 보도 사진(코스인코리아 기사)이에요. 카드에 출처를 적어 두었어요.
- [ ] **05장 사용법**: 일반 미스트 팁이에요(CJ온스타일). 제품 공식 사용법을 찾으면 Claude에게 보내 주세요. 카드를 바꿔 드려요.
- [ ] **광고 여부**: 제품이나 대가를 받았다면 캡션 맨 앞에 `#광고`

## 올리는 방법 (PC)

1. instagram.com → 왼쪽 **만들기 (+)** → **컴퓨터에서 선택**
2. 이 폴더에서 `01.png` 클릭 → **Shift** 누른 채 `07.png` 클릭 → **열기**
3. 왼쪽 아래 **크기 조절 아이콘** → **4:5** 선택 (안 하면 정사각형으로 잘려요)
4. **다음** → **다음** → `caption.txt` 내용 붙여넣기 → **공유하기**

휴대폰: OneDrive 앱에서 이 폴더의 사진 7장을 저장한 뒤, 인스타그램 앱에서 **여러 장 선택**으로 01부터 순서대로 고르세요.
