# 인스타그램 올리기 안내 — 세안 레시피 (14장 한 게시물)

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `01.png` ~ `14.png` | 카드 14장 (1080×1350, 세로 4:5) |
| `caption.txt` | 캡션 (536자, 해시태그 8개) — 그대로 복사해서 붙여넣기 |
| `프로필사진.png` | 계정 프로필 사진 (1080×1080, 믹싱볼 + 거품 + 거품기) |

카드 순서
- 01~07장: 세안할 때 다들 하는 실수 5가지
- 08~13장: 문지르지 않는 1분 팩 세안 레시피
- 14장: 실수 → 레시피 한 장 정리

## 1단계. 프로필 설정 (처음 한 번만)

인스타그램 → 프로필 → **프로필 편집**

| 칸 | 입력할 내용 |
|---|---|
| 사진 | **사진 수정** → 이 폴더의 `프로필사진.png` 선택 (동그랗게 잘려도 그림이 다 보이게 만들었어요) |
| 사용자 이름 | `weekly.beauty.recipe` |
| 이름 (닉네임) | `뷰티 레시피 \| 세안·올영템 사용법` |
| 소개 | 아래 내용 복사 |

```
🍳 뷰티 루틴을 레시피처럼 쉽게
🧴 세안 루틴 · 올리브영 제품 사용법
🔰 20~30대 뷰티 초보를 위한 카드뉴스
📌 출처는 게시물마다 표기해요
```

- 사용자 이름이 이미 있다고 나오면 Claude에게 알려 주세요. 카드 속 계정명까지 함께 바꿔 드려요.
- 이름(닉네임)은 14일 동안 바꿀 수 있는 횟수가 정해져 있어요.

## 2단계. 올리기 전 확인 (꼭 체크)

- [ ] **사진 사용 권한**: 08·09·10장에 휩드 상품 사진(올리브영 상품 페이지)이 들어 있어요. 브랜드 사진이라 허락 없이 쓰면 저작권 문제가 생길 수 있어요. 직접 찍은 사진으로 바꾸거나 사용 허락을 확인해 주세요.
- [ ] **인물 사진**: 사람이 나오는 사진(03~06장, 10장, 12~13장)을 어디서 가져왔는지 확인해 주세요. 사진 사이트에서 받았다면 사용 조건을, AI로 만들었다면 그대로 써도 돼요.
- [ ] **광고 여부**: 휩드에서 제품이나 대가를 받았다면 캡션 맨 앞에 `#광고`를 넣어 주세요.
- [ ] **프로필 설정 완료**: 1단계를 마쳤는지

## 3단계-A. PC로 올리기

1. 인터넷 창에서 **instagram.com** 에 들어가서 로그인
2. 왼쪽 메뉴에서 **만들기 (+)** 클릭
3. **컴퓨터에서 선택** → 이 폴더(`output\instagram_세안레시피_한게시물`)를 열기
4. `01.png` 를 클릭하고 **Shift 를 누른 채 `14.png` 클릭** → 14장이 한 번에 선택돼요 → **열기**
5. 아래 미리보기에서 **01 → 14 순서**인지 확인
6. **비율 바꾸기**: 왼쪽 아래 **크기 조절 아이콘** 클릭 → **4:5** 선택
   - 이걸 안 하면 정사각형으로 잘려서 카드 위아래가 사라져요
7. **다음** → (필터 없이) **다음**
8. `caption.txt` 를 열어서 전체 선택(Ctrl+A) → 복사(Ctrl+C) → 캡션 칸에 붙여넣기(Ctrl+V)
9. **공유하기** 클릭

## 3단계-B. 휴대폰으로 올리기

1. 휴대폰에서 **OneDrive 앱** → `바탕 화면` → `cardnews-bot` → `output` → `instagram_세안레시피_한게시물`
2. `01.png` ~ `14.png` 를 선택해서 **휴대폰에 저장**
3. `caption.txt` 를 열어서 내용 전체 복사
4. 인스타그램 앱 → **+** → **게시물** → 오른쪽 위 **여러 장 선택** 아이콘 → **01부터 14까지 순서대로** 누르기
5. 사진 아래 **비율 아이콘**을 눌러 **4:5** 로 맞추기 → **다음** → **다음**
6. 캡션 칸에 붙여넣기 → **공유**
