# 인스타그램 올리기 안내 — 건조한 겨울, 뭐 선물하지?

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `01.png` ~ `07.png` | 카드 7장 (1080×1350, 세로 4:5) |
| `caption.txt` | 캡션 — 그대로 복사해서 붙여넣기 |

카드 순서: 01 표지 → 02 고민 체크 → 03 DMT가 뭐예요? → 04 세트 4종 → 05 누구에게 줄까? → 06 포인트·구매처 → 07 정리

## 올리기 전 확인

- [ ] **가격**: 기사에 가격이 없어서 카드에 넣지 않았어요. "판매처에서 확인"이라고 적어 두었어요.
- [ ] **사용법**: 기사에 사용 방법이 없어서 "제품 상세 페이지에서 확인"으로 안내했어요.
- [ ] **한정 수량**: 연말 한정판이라 품절되기 전에 올리는 게 좋아요.
- [ ] **사진**: 표지·세트 사진은 코스모닝 기사 사진(홀리데이 세트 실제 구성), 토너·립밤은 피지오겔 공식몰의 **단품** 사진이에요. 4장에 "토너·립밤 사진은 단품"이라고 적어 두었어요.
- [ ] **1,300만 개**: 브랜드가 발표한 판매량이에요 (2018.1~2026.1 글로벌 누적). 카드에 "브랜드 발표 기준"이라고 적어 두었어요.
- [ ] **광고 여부**: 제품을 협찬받았다면 캡션 맨 앞에 `#광고`

## 올리는 방법 (PC)

1. instagram.com → **만들기 (+)** → **컴퓨터에서 선택**
2. `01.png` 클릭 → **Shift** 누른 채 `07.png` 클릭 → **열기**
3. 왼쪽 아래 **크기 조절 아이콘** → **4:5**
4. **다음** → **다음** → `caption.txt` 붙여넣기 → **공유하기**
