# 인스타그램 올리기 안내 — 입술이 푸석해 보인다면?

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `01.png` ~ `07.png` | 카드 7장 (1080×1350, 세로 4:5) |
| `caption.txt` | 캡션 — 그대로 복사해서 붙여넣기 |

카드 순서: 01 표지 → 02 고민 체크 → 03 재료 → 04 기본 vs 쉬머 → 05 컬러 고르기 → 06 바르는 법 → 07 정리

## 올리기 전 확인

- [ ] **매장·기간**: 장업신문 11월 10일 기사 기준이에요 (강남 타운·두타점 등, 11/1~12/31 체험 매대).
- [ ] **재료·용량·사용법**: 누니 공식몰(nooni.me, 해외몰) 제품 페이지 기준이에요. 국내 올리브영 제품과 다를 수 있으니 상세 페이지를 한 번 확인해 주세요.
- [ ] **가격**: 확인하지 않았어요. 카드에 "올리브영에서 확인"이라고 적어 두었어요.
- [ ] **컬러 사진**: 공식몰 컬러 표에서 잘라 온 입술 사진이에요. 공식몰의 효과 수치(임상 %)는 넣지 않았어요.
- [ ] **광고 여부**: 제품을 협찬받았다면 캡션 맨 앞에 `#광고`

## 올리는 방법 (PC)

1. instagram.com → **만들기 (+)** → **컴퓨터에서 선택**
2. `01.png` 클릭 → **Shift** 누른 채 `07.png` 클릭 → **열기**
3. 왼쪽 아래 **크기 조절 아이콘** → **4:5**
4. **다음** → **다음** → `caption.txt` 붙여넣기 → **공유하기**
