## 올리기 전 확인

- [ ] **원문 날짜**: Vogue 기사는 2025년 10월에 처음 나왔고 최근 갱신됐어요. 카드에 그렇게 적어 두었어요.
- [ ] **제품 4가지**: 올리브영 판매 여부와 가격은 확인하지 않았어요. 캡션에 "직접 확인"이라고 적어 두었어요.
- [ ] **제품 사진**: 4개 모두 **각 브랜드 공식몰의 제품 사진**이에요 (아누아·이니스프리 US·썸바이미·코스알엑스 공식 사이트). 카드에 "사진 · 각 브랜드 공식몰"이라고 적어 두었어요. 브랜드 사진이라 걱정되면 **직접 찍은 제품 사진**으로 바꾸는 게 가장 안전해요.
- [ ] **광고 여부**: 제품을 협찬받았다면 캡션 맨 앞에 `#광고`

## 올리는 방법 (PC)

1. instagram.com → **만들기 (+)** → **컴퓨터에서 선택**
2. `01.png` 클릭 → **Shift** 누른 채 `08.png` 클릭 → **열기**
3. 왼쪽 아래 **크기 조절 아이콘** → **4:5**
4. **다음** → **다음** → `caption.txt` 붙여넣기 → **공유하기**
