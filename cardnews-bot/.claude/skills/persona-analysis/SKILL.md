# 페르소나 분석 스킬

`@weekly.beauty.recipe` 계정의 독자(페르소나)를 기준으로
① 페르소나 카드를 만들고, ② 후보 소식과 ③ 카드 문구가 독자에게 맞는지 점검합니다.

먼저 `CLAUDE.md`의 **2. 타깃**, **3. 말투**, **4. 금지 사항**을 읽고 시작합니다.
CLAUDE.md와 이 파일이 다르면 **CLAUDE.md가 우선**입니다.

---

## 0. 지켜야 할 것

- 페르소나는 **가상의 대표 독자**입니다. 실제 통계·조사 결과처럼 쓰지 않습니다.
  - "20대의 70%가~" 같은 숫자는 출처가 없으면 쓰지 않습니다.
- 근거가 있는 내용과 추측한 내용을 나눠 적습니다.
  - 근거: CLAUDE.md, picks/candidates 기록, 지난 output, 사용자가 알려 준 내용
  - 추측: `[가정]` 표시를 붙이고, 사용자에게 맞는지 물어봅니다.
- 실제 사람(팔로워, 댓글 작성자)의 이름이나 정보를 페르소나에 넣지 않습니다.
- 결과는 쉬운 말로, 친근한 "~해요" 체로 씁니다.

---

## 1. 모드 고르기

사용자 요청에 따라 아래 셋 중 하나를 합니다. 애매하면 한 줄로 물어봅니다.

| 모드 | 이런 요청일 때 | 결과 파일 |
|---|---|---|
| A. 페르소나 만들기 | "페르소나 정리해 줘", "우리 독자 누구야?" | `personas/persona.md` |
| B. 후보 소식 점검 | "오늘 후보 중 독자한테 맞는 거?" | `personas/check_날짜.md` |
| C. 카드 문구 점검 | "cards.json 독자 눈높이 봐 줘" | `personas/check_날짜.md` |

- `personas/` 폴더가 없으면 만듭니다.
- 이미 있는 파일을 덮어쓰기 전에는 사용자에게 먼저 물어봅니다.

---

## 2. 모드 A — 페르소나 만들기

### 참고할 자료
1. `CLAUDE.md` 타깃·말투 항목
2. `picks/*.md` — 사용자가 실제로 고른 소식 (어떤 주제를 골랐는지)
3. `output/*/caption.txt` — 지금까지 올린 콘텐츠 주제
4. `used.txt` — 이미 다룬 소식

### 페르소나 2~3명 만들기
대표 페르소나 1명(메인) + 보조 1~2명. 각 페르소나는 아래 틀을 채웁니다.

```markdown
## 🙋 페르소나 1 (메인): [별명, 예: "퇴근길 올영러 지은"]

- **나이·상황**: 예) 27세, 직장인 3년 차 [가정]
- **피부 고민**: 예) 건조함, 세안 후 당김
- **뷰티 지식 수준**: 예) 성분 이름은 들어 봤지만 뜻은 잘 모름
- **올리브영 쇼핑 습관**: 예) 퇴근길·세일 기간에 들름 [가정]
- **정보를 얻는 곳**: 예) 인스타 피드, 친구 추천 [가정]
- **궁금해하는 질문 3개**:
  1. "이거 내 피부에도 맞을까?"
  2. "어떤 순서로 발라요?"
  3. "비슷한 제품이랑 뭐가 달라요?"
- **싫어하는 것**: 예) 어려운 성분 설명, 광고 같은 과장
- **저장·공유하고 싶어지는 카드**: 예) 바르는 순서 정리, 피부타입별 비교
- **이 사람에게 쓰는 한 줄**: 예) "어려운 말 없이, 오늘 바로 따라 할 수 있게"
```

### 마지막에 덧붙일 것
- **콘텐츠 방향 3줄 요약**: 이 페르소나에게 잘 맞는 주제·레이아웃(checklist / flow / compare 등)
- **확인 질문**: `[가정]`으로 적은 부분 중 사용자에게 꼭 물어볼 것 2~3개

## 3. 모드 B — 후보 소식 점검

`candidates/날짜.md` 또는 `picks/날짜.md`의 소식마다 메인 페르소나 입장에서 봅니다.
(먼저 `personas/persona.md`가 있는지 확인하고, 없으면 CLAUDE.md 타깃 기준으로 진행하면서 모드 A를 권합니다.)

| 질문 | 점수(1~5) |
|---|---|
| 이 사람이 피드에서 멈춰서 볼까? | |
| 이 사람의 고민·질문에 답해 주나? | |
| 읽고 나서 바로 따라 할 수 있나? (사용법·순서) | |
| 저장하거나 친구에게 보내고 싶을까? | |

- 합계(만점 20점)와 **한 줄 이유**를 적습니다.
- 업계 뉴스(실적, 진출, 팝업, 인수)는 "독자가 직접 쓸 수 있는 정보인지"를 따로 적습니다.
- 이 점수는 `morning.py` 자동 점수와 **별개인 참고 의견**입니다.
- **최종 선택은 사용자가 합니다.** Claude는 순위와 이유만 제안합니다.

### 결과 예시
```markdown
| 순위 | 소식 | 페르소나 점수 | 한 줄 이유 |
|---|---|---|---|
| 1 | 달바 미스트 | 15/20 | 건조한 겨울 고민과 맞고, 사용법으로 풀기 쉬워요 |
| 2 | 루나 도쿄 팝업 | 7/20 | 국내 독자가 직접 가 볼 수 없어 관심이 낮을 수 있어요 |
```

## 4. 모드 C — 카드 문구 점검

`cards.json`의 카드를 한 장씩 메인 페르소나의 눈으로 읽고 점검합니다.

### 체크리스트
- [ ] **어려운 말**: 풀이 없이 나온 성분명·전문용어가 있나? → 쉬운 말 제안
- [ ] **질문에 답하나**: 페르소나의 "궁금한 질문 3개" 중 하나라도 답하나?
- [ ] **이야기 순서**: 고민 → 해결 재료 → 원리 → 언제·어떻게 → 정리 순서인가?
- [ ] **분량**: 한 장에 3~4줄, 이모지 1~2개인가?
- [ ] **말투**: "~해요" 체이고, 과장("인생템", "무조건") 없나?
- [ ] **약처럼 표현**: "치료", "제거" 같은 표현 없나?
- [ ] **사실 근거**: 출처에 없는 효과·사용감·사용법을 쓰지 않았나?

### 결과 형식
```markdown
## 카드 3 — "히알루론산이 뭐예요?"
- 👍 좋은 점: 원리를 물 잡는 스펀지로 비유해서 쉬워요
- ✏️ 고칠 점: "경피수분손실"은 초보에게 어려워요
- 💡 바꿔 쓰기 제안: "피부 속 수분이 날아가는 것"
```

- 고칠 문구는 **제안만** 하고, `cards.json`을 직접 고치지는 않습니다.
- 사용자가 "고쳐 줘"라고 하면 그때 고칩니다.
- 새 문구도 CLAUDE.md 금지 사항(복사 금지, 지어내기 금지)을 지킵니다.

---

## 5. 끝낼 때

1. 만든 파일 경로를 알려 줍니다.
2. 결과를 3줄 이내로 요약합니다.
3. 다음 단계를 **하나만** 제안합니다. (예: "`[가정]` 부분 3개만 확인해 주실래요?")
