# 휩드(WHIPPED) 홈페이지 분석 보고서

2026-11-04 작성

## 요약

휩드는 **비건 팩클렌저 하나를 여러 '맛'으로 팔고, 그 맛을 다른 카테고리로 넓히는 브랜드**입니다. 이 보고서는 콘텐츠 마케터 지원을 준비하기 위해 자사몰과 포토리뷰를 분석했습니다.

- **주력 상품:** 머그트리 팩클렌저(리뷰 10,154개)를 중심으로 한 비건 팩클렌저, 지금은 신제품 피치페어와 무화버터 기획전을 밀고 있음
- **파악 포인트:** 고객이 리뷰에서 말하는 구매 이유(향·제형·대용량·친환경 패키지)와 클렌저에서 다른 제품으로 넘어가는 동선
- **비교 기준:** 아렌시아(신기한 제형), 비플레인(믿을 수 있는 성분)과 '히어로 클렌저를 어떤 이야기로 파는가'를 비교

## 주력 상품 분석

휩드의 주력 상품은 단연 **비건 팩클렌저**입니다. 그중에서도 **머그트리 팩클렌저**가 리뷰 10,154개로 가장 많습니다. BEST 카테고리 6개 중 3개가 팩클렌저이고, 메인 상품 8개 중 5개가 팩클렌저 단품 또는 묶음입니다.

| 순위 | 상품군 | 대표 상품 | 근거 (2026-11-04 확인) |
| --- | --- | --- | --- |
| 1 | 비건 팩클렌저 | 머그트리, 무화버터, 딸바, 호호벤더, 피치페어(신제품) | 머그트리 80g 리뷰 10,154개 / 평점 4.8, 130g 정가 29,000원 → 23,200원 |
| 2 | 팩클렌저 묶음·선물세트 | 튜브 5+1, 단지 5+1, 80g 선물 SET(5종 택1), 설 선물세트 | 각 리뷰 3,500\~5,500개, 5+1은 최대 30% 할인 |
| 3 | 비건 팩스크럽 | 라보카도, 피치페어(신제품) | BEST 4·5위, 210g 27,000원 |
| 4 | 바디 | 무화버터 토핑 바디버터 | BEST 6위, 현재 메인 메뉴 기획전 'FIGBUTTER FESTA' |
| 5 | 스킨케어·선케어 (확장 라인) | 머그트리·유자몽 앰플+크림, 피치페어 톤업 선크림 | 리뷰 120\~170개로 아직 초기 단계 |

파악 포인트는 세 가지입니다.

- **하나의 제형, 여러 맛:** 같은 팩클렌저를 피부 고민별 '맛'으로 나눠 팔고, 신제품(피치페어)을 시즌마다 추가합니다.
- **같은 '맛'으로 라인 확장:** 피치페어는 팩클렌저·팩스크럽·선크림으로, 무화버터는 클렌저·바디버터로 이어집니다. 클렌저 고객을 다른 카테고리로 드는 전략입니다.
- **묶음과 선물:** 5+1, 골라담기, 명절 세트가 메인에 전면 배치됩니다. 객단가를 올리고 선물 수요를 잡는 구조입니다.

참고: 크리마는 관련 상품끼리 리뷰를 공유해 보여주므로 묶음 상품의 리뷰 수는 단품 리뷰와 겹칠 수 있습니다.

[포토리뷰 페이지](https://whipped.co.kr/board/review/list_photo.html)의 평점은 4.8\~4.9입니다. 고객은 효능보다 '세안 경험'과 '브랜드 태도'를 더 길게 씁니다. 리뷰가 길고 감정적이라 그대로 콘텐츠 소재가 됩니다.

아쉬운 점도 리뷰에 나옵니다. 리뉴얼된 딸바 단지에서 뚜껑 안 스푼이 안으로 빠진다는 의견이 있고, 제형이 예전보다 덜 꾸덕해졌다는 평도 있습니다. 스킨케어 신제품 리뷰 상당수는 체험단 리뷰라, 자발적 입소문은 아직 클렌저에 쏠려 있습니다.

## 무엇을 중심으로 파악하면 좋은가

콘텐츠 마케터라면 '무엇을 파나'보다 '고객이 왜 사고, 왜 다시 사나'를 먼저 봐야 합니다. 아래 6가지를 홈페이지와 SNS에서 직접 확인해 보세요.

- [ ] **히어로 제품의 구매 이유:** 팩클렌저 리뷰에서 가장 자주 나오는 단어(순함, 대용량, 향, 각질)를 세어 보고 메시지 우선순위를 정하기
- [ ] **'맛' 라인업 구조:** 맛별 피부 고민(진정, 각질, 보습, 톤업)을 표로 정리하기. 추천 콘텐츠의 뼈대가 됩니다
- [ ] **신제품·시즌 캘린더:** 피치페어, 무화버터 페스타, 썸머페스타처럼 언제 무엇을 밀었는지 날짜순으로 기록하기
- [ ] **크로스셀 동선:** 클렌저 → 스크럽 → 바디 → 스킨케어로 고객을 어떻게 넘기는지 (세트 구성, 동봉 카드)
- [ ] **선물 수요:** 카카오톡 선물하기와 자사몰 선물세트의 구성, 가격대, 명절 타이밍
- [ ] **채널별 톤 차이:** 인스타그램 피드·릴스, 유튜브, 자사몰 상세페이지에서 같은 제품을 어떻게 다르게 말하는지

리뷰에서 나온 아쉬운 점(스푼 불편, 스킨케어 라인 인지도)을 개선 아이디어와 함께 제시하면 면접에서 차별화됩니다.

## 경쟁 브랜드 비교 기준

아렌시아, 비플레인과는 매출보다 \*\*'히어로 클렌저를 어떤 이야기로 파는가'\*\*를 기준으로 비교하세요. 세 브랜드 모두 클렌저 하나로 크지만, 파는 이야기가 다릅니다. 아래 표의 빈칸은 각 브랜드 공식몰·인스타그램을 보며 채우면 됩니다.

| 비교 기준 | 휩드 | 아렌시아 | 비플레인 |
| --- | --- | --- | --- |
| 히어로 제품 | 비건 팩클렌저 | 떡솝 | 녹두 약산성 클렌징폼 |
| 핵심 이야기 | 디저트 같은 힐링 세안 + 비건 | 신기한 제형 자체 | 순하고 믿을 수 있는 성분 |
| 제품 네이밍 | 맛 이름 (무화버터, 딸바) | 모찌·떡 이미지 | 원료 이름 (녹두) |
| 라인 확장 방식 | 같은 맛으로 카테고리 확장 | 확인할 것 | 확인할 것 |
| 주력 채널 | 자사몰, 카카오톡 선물하기, 플래그십 | 올리브영, 아마존·쇼피 | 올리브영, 화해, 해외 20여 개국 |
| 가격·묶음 | 130g 23,200원, 5+1 최대 30% | 확인할 것 | 확인할 것 |
| 리뷰 핵심 키워드 | 향, 제형, 대용량, 패키지, 컨셉 | 확인할 것 | 확인할 것 |
| SNS 콘텐츠 포맷 | 확인할 것 | 제형 숏폼 중심 | SNS 해외 마케팅 |
| 신뢰 장치 | 비건 인증, 평점 4.8, 누적 판매량 | 올리브영 어워즈 2025 라이징스타 | 화해 어워드 3년 연속 1위 |

비교하는 방법은 다음 순서가 좋습니다.

1. 각 브랜드 자사몰 BEST 1위 제품의 상세페이지 첫 화면 문구를 비교합니다.
2. 히어로 제품의 리뷰 30개씩을 읽고 자주 나오는 단어를 세어 봅니다.
3. 인스타그램 최근 게시물 12개의 포맷(릴스, 카드뉴스, 연출컷)과 반응을 비교합니다.
4. 마지막에 '휩드가 경쟁사에서 배울 점 1가지, 휩드만 할 수 있는 것 1가지'로 결론을 냅니다.

## 지원서·면접 활용 제안

- **지원동기:** 리뷰 문장을 인용해 '고객은 효능보다 힐링되는 세안 경험을 산다'는 인사이트로 시작하세요.
- **포트폴리오:** 피치페어 신제품으로 릴스 기획안 1개를 만드세요 (예: '오늘 내 피부에 맞는 맛 고르기').
- **개선 제안:** 스킨케어·선케어 라인을 팩클렌저 고객에게 자연스럽게 알리는 '같은 맛 루틴' 콘텐츠를 제안하세요.
