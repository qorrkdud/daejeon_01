# 콘텐츠 마케터 인턴 면접 준비

## 목적
사용자가 만든 포트폴리오(페르소나 분석)와 자기소개서·이력서를 **말로 설명하고 방어할 수 있게** 돕는다.
인턴 면접은 경험의 양보다 **성장 가능성, 태도, 생각하는 방식**을 본다는 점을 기준으로 질문을 만든다.

```
⓪ 시작 설정 → ① 자료 읽기 + 포트폴리오 면접 요약 → ② 1분 자기소개 + 예상 질문 + 즉석 과제 정리
→ ③ 모의 면접 → ④ 종합 리포트
```

---

## 0단계. 시작 설정

처음에 아래를 확인한다. 이미 알고 있는 값은 다시 묻지 않는다.

| 항목 | 기본값 |
|---|---|
| 회사 | 휩드(WHIPPED) |
| 직무 | 콘텐츠 마케터 인턴 |
| 면접 종류 | 실무 + 인성 (과제·PT 면접이 있다고 하면 추가) |
| 포트폴리오 자료 | `휩드_페르소나분석_YYYYMMDD/` 폴더 중 가장 최근 것 |
| 기타 포트폴리오 | 카드뉴스, 논문, 브랜드 기획 등. 사용자에게 파일 위치를 묻거나 요약을 요청 |
| 자기소개서·이력서 | 사용자에게 파일 위치를 묻거나 붙여넣기를 요청 |
| 진행 방식 | ② 질문 정리 → ③ 모의 면접 순서. 사용자가 원하면 하나만 진행 |
| 모의 면접 문항 수 | 시작할 때 사용자가 선택: **짧게 5문항** 또는 **실전 10문항** |

자기소개서·이력서가 없으면 그 자료에서 나오는 질문은 건너뛰고, 건너뛴 사실을 알려 준다.

## 1단계. 자료 읽기

### 1-1. 포트폴리오 (페르소나 분석 결과)
`휩드_페르소나분석.md`, `data/reviews.csv`, 캠페인 제안을 읽고 아래를 뽑는다.
- **핵심 주장**: 핵심 페르소나, 1순위 기회, 경쟁사 대비 차별점, 캠페인명
- **사용한 숫자**: "리뷰 N개 중 M개(○%)" 같은 수치와 그 출처
- **분석의 한계**: 모수, 채널 편향, 추정으로 표시한 부분
- **면접관이 찌를 만한 곳**: 근거가 약하거나 설명이 필요한 부분

### 1-2. 기타 포트폴리오 (카드뉴스, 논문, 브랜드 기획 등)
항목마다 아래를 한 줄씩 정리한다. 1분 자기소개와 다른 답변에서 계속 꺼내 쓰는 재료가 된다.
- **무엇을 했나**: 주제와 결과물 형태
- **내 역할과 방법**: 직접 한 일, 쓴 방법(리서치, 데이터 분석, 디자인 등)
- **성과·숫자**: 있으면 (조회수, 저장 수, 평가 결과 등)
- **콘텐츠 마케터와 연결되는 역량**: 예) 논문 → 리서치와 근거 정리, 브랜드 기획 → 타깃과 메시지 설계, 카드뉴스 → 콘텐츠 제작과 반응 분석
- **휩드와 연결되는 지점**: 비건, 스킨케어, 고객 리뷰, 브랜드 톤 등

### 1-3. 자기소개서·이력서
- 경험마다 **상황, 내 역할, 행동, 결과(숫자), 배운 점**을 정리한다.
- 자기소개서에 쓴 **강한 표현**(예: "주도했다", "성과를 냈다")을 따로 표시한다. 꼬리 질문이 가장 많이 나오는 곳이다.
- 포트폴리오와 자기소개서가 **서로 연결되는 지점**을 찾는다. (예: 자소서의 "데이터 기반 기획" ↔ 리뷰 직접 집계)

**규칙**
- 사용자의 경험을 지어내지 않는다. 자료에 없는 내용은 답변 방향에 **[본인 경험으로 채우기]**라고 표시한다.
- 포트폴리오와 자기소개서의 내용이 서로 어긋나면(숫자, 역할 등) 따로 알려 준다.

### 1-4. 포트폴리오 면접 요약
1-1에서 읽은 페르소나 분석 결과를 **면접에서 바로 말할 수 있는 분량**으로 압축한다.
이 요약은 1분 자기소개(2-5)의 ② 대표 경험, B·C 카테고리 답변, 즉석 과제(2-6)의 근거로 계속 쓰인다.

| 항목 | 내용 | 분량 |
|---|---|---|
| 30초 답변 | "휩드의 핵심 고객은 누구라고 생각하나요?"에 대한 답. 포트폴리오 말투, 숫자 1개 이상 | 3~4문장 |
| 핵심 발견 3가지 | 리뷰 집계, 불만에서 찾은 기회, 경쟁사 대비 차별점에서 하나씩 | 각 한 줄 + 근거 숫자 |
| 캠페인 한 줄 요약 | "○○한 [핵심 페르소나]에게, △△을 통해 □□을 느끼게 한다." | 1문장 |
| 꼭 기억할 숫자 | 면접에서 쓸 숫자와 그 숫자를 어떻게 셌는지 | 최대 5개 |

**규칙**
- 페르소나 분석 결과에 있는 숫자만 쓴다. 숫자를 새로 만들거나 반올림으로 바꾸지 않는다.
- 숫자마다 분석 문서의 어느 항목에서 왔는지 적어 둔다. 꼬리 질문("어떻게 셌나요?")에 대비하기 위해서다.
- 페르소나 분석 결과 폴더가 없으면 이 항목은 건너뛰고, 사용자에게 먼저 페르소나 분석 스킬을 실행하도록 안내한다.

## 2단계. 예상 질문 + 답변 방향 정리

### 2-1. 질문 카테고리

| 카테고리 | 다루는 내용 | 질문 예시 |
|---|---|---|
| A. 지원 동기·회사 이해 | 왜 이 회사, 왜 콘텐츠 마케터 | "휩드 콘텐츠 중 가장 인상 깊었던 건?", "휩드를 한 문장으로 소개한다면?" |
| B. 포트폴리오 | 페르소나 분석 방법, 결과, 한계 | "리뷰 50개로 충분하다고 봤나요?", "핵심 페르소나를 그렇게 정한 이유는?" |
| C. 캠페인 제안 | 실행 가능성, KPI, 리스크 | "이 캠페인을 다음 주에 시작한다면 첫 번째로 할 일은?" |
| D. 자기소개서·경험 | 경험별 역할과 결과 | "그 프로젝트에서 본인이 직접 한 일은?" |
| E. 콘텐츠 실무 감각 | 트렌드, 성과 측정, 툴, 즉석 아이디어 | "요즘 눈여겨보는 브랜드 계정은?", "릴스 성과가 낮으면 무엇부터 보나요?" |
| F. 인성·태도 | 협업, 갈등, 피드백 수용, 실패 | "기획안이 반려되면 어떻게 하나요?" |
| G. 역질문 | 마지막에 하고 싶은 질문 | 면접관에게 할 질문 2~3개 |
| H. 즉석 콘텐츠 과제 | 그 자리에서 근거 있는 아이디어 내기 | "지금 휩드 클렌저 릴스 아이디어 3개 말해 보세요" (2-6 참고) |

**인턴 면접 기준 비중**: B·C(포트폴리오) 25% / A 15% / E 15% / H 15% / D 15% / F 15%
1분 자기소개(2-5)는 비중과 상관없이 항상 첫 질문으로 준비하고,
G(역질문)는 질문 수와 상관없이 항상 2~3개를 준비한다.

### 2-2. 질문마다 정리할 내용

```
### Q. 질문
- 중요도: 필수 / 높음 / 보통
- 질문 의도: 면접관이 이 질문으로 확인하려는 것
- 답변 뼈대:
  1. 결론 (한 문장)
  2. 근거 (숫자, 자료)
  3. 경험 또는 과정
  4. 휩드·직무와 연결
- 꼭 넣을 숫자·근거: "리뷰 N개 중 M개(○%)" (출처: 분석 문서 몇 번 항목)
- 예상 꼬리 질문: 2~3개
- 피해야 할 답: 흔한 실수 1~2개
```

답변 뼈대는 **키워드 수준**으로만 쓴다. 완성된 문장은 쓰지 않는다. 사용자가 자기 말로 답하게 하기 위해서다.

### 2-3. 약점 방어 노트
면접관이 찌를 만한 약점을 따로 모아, 약점마다 **인정 → 보완한 점 → 다음에 하고 싶은 것**의 순서로 방어 논리를 정리한다.

- 예상 약점 예시: 리뷰 모수가 작다, 실무 경험이 없다, 내부 데이터 없이 추정했다, 캠페인의 실행 가능성
- 예시:
  > 인정: "리뷰 50개는 전체를 대표하기엔 적은 숫자라고 생각합니다."
  > 보완: "그래서 채널 두 곳에서 나눠 모았고, 비율보다는 반복되는 표현에 집중했습니다."
  > 다음: "입사한다면 자사몰 전체 리뷰로 같은 분석을 다시 해 보고 싶습니다."

### 2-4. 저장
`면접준비_회사_YYYYMMDD.md` 파일로 저장한다.

문서 순서
1. 포트폴리오 면접 요약 (1-4): 30초 답변, 핵심 발견 3가지, 캠페인 한 줄 요약, 꼭 기억할 숫자
2. 1분 자기소개 (2-5)
3. 카테고리별 예상 질문 (중요도 순서)
4. 즉석 콘텐츠 과제 연습 세트 (2-6)
5. 약점 방어 노트
6. 역질문 리스트
7. 자료 간 어긋나는 점 (있으면)

### 2-5. 1분 자기소개
면접에서 거의 반드시 나오는 질문이다. 여기서 정한 **핵심 키워드와 숫자**는 다른 답변에서도 계속 쓴다.

**재료**: 1-1 페르소나 분석, 1-2 기타 포트폴리오(카드뉴스, 논문, 브랜드 기획), 1-3 자기소개서

**구조 (약 1분, 300~350자)**

| 순서 | 내용 | 분량 |
|---|---|---|
| ① 한 줄 정체성 | "저는 ○○하는 콘텐츠 마케터 지원자 △△입니다." 나를 설명하는 키워드 1개 | 1문장 |
| ② 대표 경험 | 포트폴리오 중 휩드와 가장 가까운 것 1개 (보통 휩드 페르소나 분석) + 숫자 1개 | 2~3문장 |
| ③ 역량의 일관성 | 다른 포트폴리오(논문, 브랜드 기획, 카드뉴스)가 같은 역량으로 이어진다는 것을 한 문장으로 | 1~2문장 |
| ④ 휩드와 연결 | 왜 휩드 콘텐츠 마케터인지, 들어가서 무엇을 하고 싶은지 | 1~2문장 |

**규칙**
- 포트폴리오를 나열하지 않는다. **하나의 키워드**(예: "근거로 기획하는 사람")로 모든 경험을 꿰어 말한다.
- 숫자는 1~2개만 쓴다. 많으면 기억에 남지 않는다.
- 세 가지 버전을 만든다.
  - **30초 버전**: ①②④만
  - **1분 버전**: 기본
  - **키워드 카드**: 외우지 않고 말할 수 있게 순서별 키워드만 정리
- 완성 문장 예시는 1분 버전에만 제공하고, 사용자가 자기 말로 바꿔 연습하도록 안내한다.
- 자기소개에 넣은 경험은 꼬리 질문이 반드시 나오므로, 경험마다 예상 꼬리 질문 2개를 함께 정리한다.

### 2-6. 즉석 콘텐츠 과제
콘텐츠 마케터 면접에서 가장 차이가 나는 부분은 **그 자리에서 근거 있는 아이디어를 내는 순발력**이다.
아이디어가 좋은지보다 **고객 근거에서 출발하는지**를 연습한다.

**답변 공식: 근거 → 아이디어 → 형식·채널 → 측정**
> "리뷰 52개 중 14개(27%)에서 사용법이 헷갈린다는 불만이 있었습니다. **(근거)**
> 그래서 1분 안에 따라 할 수 있는 세안 레시피 릴스를 제안합니다. **(아이디어)**
> 핵심 페르소나가 아침에 바쁘다는 점을 고려해 15초 컷으로 만들고, 인스타 릴스와 상세페이지에 함께 씁니다. **(형식·채널)**
> 저장 수와, 이후 리뷰에서 사용법 불만이 줄어드는지로 효과를 보겠습니다. **(측정)**"

**근거로 쓸 재료** (페르소나 분석 결과에서 가져온다)
- 핵심 페르소나와 나머지 2명의 특징
- 리뷰 통계: 만족 키워드, 불만 키워드, 구매 동기, 재구매 비율
- 불만 리뷰에서 찾은 기회 (1순위 기회)
- 경쟁사 대비 차별점
- 휩드 브랜드 톤

**과제 유형** (연습 세트에 유형별로 1~2개씩 만든다)
| 유형 | 과제 예시 |
|---|---|
| 포맷 지정 | "휩드 클렌저 릴스 아이디어 3개 말해 보세요" |
| 페르소나 지정 | "두 번째 페르소나를 위한 카드뉴스 주제를 정해 보세요" |
| 불만 해결 | "'거품이 안 난다'는 리뷰가 많다면 어떤 콘텐츠를 만들겠어요?" |
| 시즌·이슈 | "환절기(또는 여름휴가) 시즌 콘텐츠를 기획해 보세요" |
| 트렌드 활용 | "요즘 유행하는 밈이나 포맷을 휩드에 적용해 보세요" |
| 위기 대응 | "부정적인 후기 댓글이 달렸다면 어떻게 답하겠어요?" |
| 제약 조건 | "예산 없이, 촬영 장비는 휴대폰 하나로 할 수 있는 콘텐츠는?" |

**연습 세트에 정리할 내용 (과제마다)**
```
### 과제. 내용
- 유형:
- 쓸 수 있는 근거: 페르소나 분석의 어느 숫자·발견
- 좋은 답의 방향: 키워드 수준으로 (완성 문장은 쓰지 않는다)
- 흔한 실수: 근거 없이 "재밌을 것 같아서", 휩드가 아닌 어떤 브랜드에도 통하는 아이디어 등
- 예상 꼬리 질문: "그중 하나만 고른다면?", "성과가 안 나오면?"
```

---

## 3단계. 모의 면접

### 3-1. 진행 규칙
- 시작 전에 문항 수(5 또는 10)를 확인하고, "지금부터 시작하겠습니다"라고 알린 뒤 첫 질문을 던진다.
- **질문은 한 번에 하나만** 한다. 사용자가 답할 때까지 기다린다.
- 첫 질문은 항상 **1분 자기소개**다. 그다음부터 카테고리 비중(2-1)에 맞춰 섞는다.
- **즉석 콘텐츠 과제**는 5문항이면 1개, 10문항이면 2개 이상 넣는다. 과제를 낸 뒤 "30초 정도 생각하셔도 됩니다"라고 안내한다.
  꼬리 질문에서는 근거를 묻거나("그 아이디어는 어떤 고객 반응에서 나왔나요?"), 하나만 고르게 하거나, 조건을 바꾼다("예산이 없다면요?").
- 모의 면접 중에는 2단계의 답변 방향을 보여 주지 않는다.
- 면접관 말투는 실제 면접처럼 정중한 존댓말로 한다.

### 3-2. 면접관 스타일: 실전형
- 본 질문 하나에 **꼬리 질문을 2~3번** 이어서 한다.
- 꼬리 질문은 미리 정한 목록이 아니라 **사용자가 방금 한 답변**에서 만든다.
  - 숫자 없이 말했으면 → "구체적으로 얼마나요?"
  - "우리가 했다"고 했으면 → "그중 본인이 직접 한 일은 무엇인가요?"
  - 결론이 모호하면 → "그래서 한 문장으로 정리하면요?"
  - 포트폴리오 숫자를 말했으면 → 그 숫자를 어떻게 셌는지, 한계는 무엇인지
- 답변이 충분히 명확하면 꼬리 질문을 2번에서 멈춘다.

### 3-3. 사용자가 쓸 수 있는 명령
| 명령 | 동작 |
|---|---|
| `패스` | 이 질문을 건너뛰고 리포트에 "다시 연습할 질문"으로 표시 |
| `다시` | 같은 질문에 다시 답하기 |
| `힌트` | 답변 뼈대의 1번(결론 방향)만 살짝 보여 주기 |
| `종료` | 바로 끝내고 종합 리포트로 넘어가기 |
| `자기소개` | 1분 자기소개만 반복 연습 (매번 피드백 후 다시 말하기) |
| `즉석과제` | 즉석 콘텐츠 과제만 연속으로 연습 (유형을 바꿔 가며) |

### 3-4. 답변별 피드백 (즉시)
본 질문과 꼬리 질문이 모두 끝나면, 다음 질문으로 넘어가기 전에 **짧게** 피드백한다.

```
[피드백]
- 좋았던 점: 1줄
- 고칠 점: 1줄 (가장 중요한 것 하나만)
- 이렇게 말해 보세요: 고친 답변의 첫 문장 예시 1개
```

**즉석 콘텐츠 과제 피드백**은 위 3줄에 더해, 답변 공식 4단계를 체크한다.
```
근거 ○/✕ · 아이디어 ○/✕ · 형식·채널 ○/✕ · 측정 ○/✕
```

**1분 자기소개 피드백**은 위 3줄에 더해 아래를 확인한다.
- 예상 길이(글자 수 기준 300~350자면 약 1분)
- 하나의 키워드로 경험이 꿰어졌는지
- 휩드와의 연결이 마지막에 분명한지

## 4단계. 종합 리포트 (모의 면접 종료 후)

### 4-1. 평가 기준 (각 1~5점)
| 기준 | 보는 점 |
|---|---|
| 답변 구조 | 결론을 먼저 말하는가, 흐름이 정리돼 있는가 |
| 숫자·근거 | 포트폴리오의 숫자와 근거를 정확히 쓰는가 |
| 답변 길이 | 본 질문 기준 1분 안팎, 너무 짧거나 길지 않은가 |
| 콘텐츠 마케터 관점 | 고객(페르소나), 채널, 반응, 성과 측정의 언어로 생각하는가 |
| 회사 이해도 | 휩드의 제품, 톤, 고객을 정확히 알고 말하는가 |
| 즉석 아이디어 | 근거 → 아이디어 → 형식·채널 → 측정 순서로, 휩드 고객에게 맞는 아이디어를 내는가 |

점수마다 그렇게 판단한 이유를 사용자의 실제 답변을 인용해 한 줄로 쓴다.

### 4-2. 리포트 구성
1. 기준별 점수와 이유
2. 가장 잘한 답변 1개와 그 이유
3. **가장 먼저 고칠 점 3가지** (구체적인 방법 포함)
4. 다시 연습할 질문 목록 (`패스`한 질문 포함)
5. 다음 모의 면접 추천: 어떤 카테고리를 더 연습하면 좋을지

### 4-3. 기록 저장
`모의면접기록_YYYYMMDD.md`로 질문, 사용자 답변, 피드백, 리포트를 저장한다.
이전 기록이 있으면 **지난번 점수와 비교**해서 좋아진 점과 여전한 점을 리포트 맨 앞에 쓴다.

## 톤 가이드
- **면접관 역할**: 정중하지만 군더더기 없이 묻는다. 칭찬이나 반응으로 답을 유도하지 않는다.
- **피드백 역할**: 솔직하고 구체적으로 말한다. "좋아요" 대신 무엇이 왜 좋은지 말한다.
- **답변 예시 문장**: 페르소나 분석 스킬의 포트폴리오 말투와 같게 쓴다.
  1인칭 "~습니다" 체, **"무엇을 봤고 → 무엇을 발견했고(숫자) → 그래서 이렇게 했다"** 순서.

## 다른 회사에 쓸 때
- 0단계에서 회사와 직무만 바꾸면 된다.
- 포트폴리오가 그 회사 분석이 아니면 B·C 카테고리를 "보유 포트폴리오 설명" 질문으로 바꾸고,
  A 카테고리는 웹에서 그 회사의 최근 콘텐츠와 브랜드 방향을 찾아 질문을 만든다.
