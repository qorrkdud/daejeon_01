# 휩드(WHIPPED) 고객 페르소나 분석

## 목적
휩드 입사를 준비하는 사용자가 **"휩드의 고객은 누구이고, 그 고객에게 무엇을 말해야 하는가"**를
직접 분석한 결과물로 보여 줄 수 있게 돕는다.

결과물은 하나의 흐름으로 이어진다.

```
① 웹 리서치(글 + 사진) → ② 리뷰 직접 집계·분석(+ 불만에서 찾은 기회) → ③ 경쟁사 비교
→ ④ 페르소나 3명 도출 → ⑤ 시각 자료 제작(그래프·사진) → ⑥ 카드뉴스
→ ⑦ 캠페인 제안("내가 휩드 마케터라면")
```

면접 준비(면접용 요약, 예상 질문, 모의 면접)는 이 스킬에서 다루지 않는다.

앞 단계의 발견이 다음 단계의 근거가 되어야 한다. 카드뉴스의 문장, 그래프, 사진은 모두
② 리뷰 분석이나 ④ 페르소나에서 찾은 근거로 거슬러 올라갈 수 있어야 한다.

**자료의 우선순위**
- 통계: **직접 집계한 리뷰 통계 > 경쟁사 비교 수치 > 기사·리포트 속 시장 통계**
- 사진: **휩드 공식 사진(주) > AI 생성 이미지(보충)**

## 1단계. 웹 리서치

웹 검색과 페이지 읽기로 아래 자료를 모은다. 검색어는 한국어를 기본으로 한다.

| 자료 | 찾는 곳 (예시) | 얻을 것 |
|---|---|---|
| 브랜드 공식 정보 | 공식 홈페이지, 자사몰, 공식 인스타그램 | 브랜드 철학, 대표 제품, 공식 말투, **공식 사진** |
| 고객 리뷰 | 올리브영, 쿠팡, 네이버 쇼핑, 자사몰 리뷰 | 리뷰 원문, **별점**, 실제 고객의 표현 |
| SNS·커뮤니티 반응 | 인스타그램, 블로그 후기, 유튜브 댓글, 화해 | 사용 장면, 추천 이유, 입소문 포인트 |
| 기사·보도자료·리포트 | 뉴스 검색, 업계 리포트 | 시장 규모, 성장률, 브랜드 성과 |

검색어 예시: `휩드 팩클렌저 후기`, `휩드 비건 클렌저 리뷰`, `WHIPPED 휩드 인스타`, `휩드 올리브영`, `휩드 브랜드 인터뷰`, `비건 화장품 시장 규모`, `클렌징 시장 동향`

### 1-1. 공식 사진 수집
- 공식 홈페이지와 자사몰 상세페이지에서 **제품 컷, 텍스처 컷, 사용 장면 컷, 브랜드 무드 컷**을 찾는다.
- 사진마다 아래를 기록한다.

  | 번호 | 이미지 URL | 사진이 있는 페이지 URL | 내용 설명 | 어울리는 카드뉴스 장 |
  |---|---|---|---|---|

- 사진 파일은 **포트폴리오 제작용**으로만 `images/official/` 폴더에 저장하고,
  사용하는 곳마다 **"출처: 휩드 공식 홈페이지"** 크레딧을 붙인다.
- 저장할 수 없는 사진은 URL과 설명만 기록하고 넘어간다.

### 1-2. 공통 규칙
- 모든 자료는 **출처 URL과 확인 날짜**를 함께 기록한다.
- 리뷰는 **최소 50개 이상**, 서로 다른 채널 2곳 이상에서 모은다. 리뷰마다 채널, 별점, 작성일, 원문을 남긴다.
- 접근할 수 없는 페이지(로그인 필요 등)는 건너뛰고, 건너뛴 사실을 문서에 적는다.
- 확인되지 않은 수치나 사실은 만들지 않는다. 추측은 반드시 **"(추정)"**이라고 표시한다.

## 2단계. 리뷰 직접 집계·분석 (이 스킬의 중심)

모은 리뷰를 `data/reviews.csv`로 정리한 뒤, **직접 세어서 숫자로 말한다.**

`reviews.csv` 열: `번호, 채널, 별점, 작성일, 원문, 피부고민, 구매동기, 사용상황, 만족키워드, 불만키워드, 재구매언급(Y/N)`

### 2-1. 분류 틀
| 분석 축 | 질문 |
|---|---|
| 피부 고민 | 어떤 피부 문제 때문에 샀나? (예: 트러블, 건조함, 모공) |
| 구매 동기 | 왜 하필 휩드였나? (비건, 성분, 패키지, 추천, 가격) |
| 사용 상황 | 언제, 어떻게 쓰나? (아침 세안, 이중 세안, 여행용) |
| 만족 포인트 | 무엇이 좋았나? |
| 불만·아쉬움 | 무엇이 아쉬웠나? |
| 재구매·추천 이유 | 다시 사거나 남에게 추천하는 이유는? |

### 2-2. 꼭 만들어야 하는 리뷰 통계
1. **별점 분포**: 1~5점 각각 몇 개인지, 평균 별점
2. **만족 키워드 TOP 10**: 언급 횟수와 전체 리뷰 대비 비율
3. **불만 키워드 TOP 5**: 언급 횟수와 비율
4. **구매 동기 비율**: 비건, 성분, 추천, 패키지, 가격 등의 구성비
5. **피부 고민 비율**: 고민 유형별 구성비
6. **재구매 언급 비율**: 재구매나 추천 의사를 밝힌 리뷰의 비율
7. **채널별 차이**: 채널마다 평균 별점과 자주 나오는 키워드가 어떻게 다른지

**규칙**
- 숫자는 항상 **"리뷰 N개 중 M개(○%)"** 형식으로, 모수(N)를 함께 쓴다.
- 키워드는 같은 뜻끼리 묶는다. (예: "촉촉", "안 당김", "보습" → **보습감**) 묶은 기준을 문서에 적는다.
- 각 통계마다 대표 리뷰 원문 1~2개를 함께 인용한다.
- 모수가 작아 일반화하기 어려우면 그 한계를 문서에 솔직하게 적는다.

### 2-3. 불만 리뷰에서 찾은 기회
불만 키워드 TOP 5를 **"약점"이 아니라 "기회"**로 다시 읽는다. 불만마다 아래 표를 채운다.

| 불만 키워드 | 비중 (N개 중 M개) | 대표 리뷰 원문 | 진짜 원인 (추정) | 콘텐츠로 풀기 | 상품·서비스로 풀기 | 우선순위 |
|---|---|---|---|---|---|---|

- **진짜 원인**: 제품 문제인지, 사용법을 몰라서인지, 기대와 달라서인지 구분한다.
  (예: "거품이 안 나요" → 제품 문제가 아니라 사용법 안내가 부족했을 수 있음)
- **콘텐츠로 풀기**: 사용법 가이드, 오해를 푸는 Q&A, 비포·애프터처럼 마케팅으로 해결할 수 있는 방법
- **상품·서비스로 풀기**: 용량, 패키지, 구성, 샘플처럼 상품 쪽에서 제안할 수 있는 방법 (제안 수준으로만 쓴다)
- **우선순위**: 비중이 크고 + 핵심 페르소나와 관련 있고 + 콘텐츠로 빨리 풀 수 있는 것을 1순위로 둔다.

마지막에 결론을 한 문장으로 쓴다.
> "가장 큰 기회는 ○○이다. 리뷰 N개 중 M개가 이 불편을 말했고, 이는 콘텐츠로 바로 풀 수 있다."

이 결론은 7단계 캠페인 제안의 출발점이 된다.

## 3단계. 경쟁사 비교

검색으로 휩드와 비슷한 위치에 있는 브랜드 2~3곳을 찾는다.
(비건 클렌징, 순한 세안제, 같은 채널에서 팔리는 클렌저 등. 어떤 기준으로 골랐는지 문서에 적는다.)

비교표 (수치는 같은 채널, 같은 날짜 기준으로 확인한다):

| 항목 | 휩드 | 경쟁사 A | 경쟁사 B |
|---|---|---|---|
| 대표 제품 | | | |
| 평균 별점 | | | |
| 리뷰 수 | | | |
| 용량당 가격 (원/ml 또는 원/g) | | | |
| 핵심 메시지 | | | |
| 고객이 칭찬하는 점 | | | |
| 고객이 아쉬워하는 점 | | | |
| 주 고객층 (추정) | | | |

경쟁사 리뷰도 가능하면 20개 이상 살펴보고, 휩드의 만족 키워드 TOP 3가 경쟁사 리뷰에서는 얼마나 나오는지 비교한다.

비교의 결론은 한 문장으로 쓴다.
> "경쟁사 고객이 ○○을 이유로 고른다면, 휩드 고객은 △△을 이유로 고른다."

### 시장 통계 (보조)
기사나 리포트에서 비건 화장품, 클렌징 시장의 공개 수치를 1~3개 인용한다.
**출처, 발행 기관, 발행 연도**를 반드시 붙이고, 출처가 불분명한 수치는 쓰지 않는다.

## 4단계. 페르소나 3명 도출

2·3단계의 근거로 페르소나 3명을 만든다. 그중 **1명을 핵심 페르소나**로 정한다.
페르소나는 상상으로 그리는 인물이 아니라 **비슷한 리뷰를 묶은 그룹의 대표**다.
그래서 "어떻게 나눴는지"를 숫자로 보여 줄 수 있어야 한다.

```
4-1 분류 축 정하기 → 4-2 리뷰 태깅 → 4-3 그룹 나누기 → 4-4 검증
→ 4-5 핵심 페르소나 선정 → 4-6 페르소나 프로필 작성
```

### 4-1. 분류 축 정하기
2단계에서 분류한 항목 중 고객을 **가장 잘 갈라 주는 축 2개**를 고른다.

| 축 후보 | 값 예시 |
|---|---|
| 피부 고민 | 트러블, 건조함, 모공·피지, 민감, 특별한 고민 없음 |
| 구매 동기 | 비건·성분 가치, 효과, 추천·입소문, 패키지·재미, 가격 |
| 사용 상황 | 아침 세안, 저녁 이중 세안, 여행·운동 후, 선물 |
| 경험 수준 | 첫 클렌저 고민, 여러 브랜드를 써 본 비교형, 휩드 재구매 |
| 가치관 신호 | 비건·동물실험·환경 언급 있음 / 없음 |

**좋은 축의 조건**
- **채워지는 비율**: 리뷰의 60% 이상에서 값을 알 수 있다. (대부분 "모름"이면 축으로 쓰지 않는다.)
- **고르게 갈림**: 한 값에 80% 이상 몰리지 않는다.
- **메시지가 달라짐**: 값에 따라 해야 할 말이 달라진다. 값이 달라도 같은 말을 하게 된다면 좋은 축이 아니다.

고른 축 2개와 고른 이유를 문서에 적는다.

### 4-2. 리뷰 태깅
`data/reviews.csv`에 아래 열을 추가해서 리뷰마다 채운다.

`경험수준, 가치관신호, 알게된경로, 사용시간대, 함께쓰는제품, 페르소나`

**규칙**
- 리뷰에 근거가 없는 칸은 추측하지 않고 **"모름"**으로 둔다.
- 한 리뷰에 피부 고민이 여러 개면 **가장 먼저, 가장 강하게** 말한 것 하나만 주 값으로 쓴다.
- 짧은 리뷰("좋아요", "배송 빨라요")는 태깅 대상에서 빼고, 뺀 개수를 기록한다.

### 4-3. 그룹 나누기
1. **교차표 만들기**: 축 2개로 표를 만들고 칸마다 리뷰 수를 센다.

   | | 비건·성분 가치 | 효과 | 추천·입소문 | 가격 |
   |---|---|---|---|---|
   | 트러블 | 8 | 12 | 3 | 1 |
   | 건조함 | 6 | 4 | 2 | 2 |
   | 민감 | 9 | 2 | 1 | 0 |
   *(숫자는 형식 예시)*

2. **후보 그룹 뽑기**: 리뷰가 많은 칸부터 후보 그룹 4~6개를 뽑는다.
3. **3개로 합치기**: 후보끼리 **해야 할 말(메시지)이 같으면** 합친다. 3개로 줄어들 때까지 반복한다.
4. **리뷰 배정**: 모든 태깅 리뷰에 `페르소나` 열을 A / B / C / 기타로 채운다.
5. **차이 확인**: 그룹마다 4-2의 나머지 열(경험 수준, 사용 시간대, 알게 된 경로 등)의 분포를 다시 센다.
   그룹 사이에 차이가 뚜렷한 항목이 그 페르소나의 특징이 된다.

교차표, 합친 과정, 그룹별 리뷰 수를 문서에 남긴다. **이 과정이 면접에서 "어떻게 나눴나요?"에 대한 답이 된다.**

### 4-4. 검증
세 그룹이 진짜 서로 다른 고객인지 확인한다. 하나라도 통과하지 못하면 4-3으로 돌아가 다시 나눈다.

| 체크 | 기준 | 통과 못 하면 |
|---|---|---|
| 크기 | 그룹마다 리뷰 8개 이상, 또는 태깅 리뷰의 15% 이상 | 다른 그룹과 합치거나 "(근거 약함)" 표시 |
| 기타 비율 | "기타" 리뷰가 30% 이하 | 축을 다시 고른다 |
| 메시지 차이 | 세 페르소나에게 해야 할 한 마디가 서로 다르다 | 같은 문구가 둘에게 통하면 합친다 |
| 블라인드 테스트 | 그룹마다 리뷰 원문 3개를 섞어 놓고, 원문만 보고 어느 페르소나인지 맞힐 수 있다 | 특징이 흐리다는 뜻. 축이나 경계를 조정한다 |

검증이 끝나면 페르소나마다 **근거 강도**를 표시한다.
- **강**: 리뷰 15개 이상, 채널 2곳 이상에서 확인
- **중**: 리뷰 8~14개, 또는 채널 1곳
- **약**: 그 미만. 카드뉴스나 캠페인의 주인공으로 쓰지 않는다.

### 4-5. 핵심 페르소나 선정
세 페르소나를 아래 기준으로 1~3점씩 매기고, 합계가 가장 높은 페르소나를 핵심으로 정한다. 점수표와 이유를 문서에 남긴다.

| 기준 | 보는 것 |
|---|---|
| 규모 | 태깅 리뷰 중 비중 (예: "52개 중 21개(40%)") |
| 차별점 반응 | 3단계 결론(휩드만의 차별점)을 리뷰에서 얼마나 자주 말하는가 |
| 충성도 | 재구매·추천 언급 비율 |
| 기회 연결 | 2-3단계의 1순위 기회(불만)와 얼마나 관련 있는가 |

근거 강도가 "약"인 페르소나는 점수와 상관없이 핵심이 될 수 없다.

### 4-6. 페르소나 프로필 작성
모든 항목 끝에 근거를 붙인다. 리뷰에서 나온 내용은 **[리뷰 #번호]**, 근거가 없는 내용은 **(추정)**으로 표시한다.

- 색은 **휩드 공식 사진에서 뽑은 브랜드 컬러 1~2개**를 쓰고, 핵심 페르소나나 휩드는 진한 색, 나머지는 연한 회색으로 둔다.

  (예: "리뷰 10개 중 4개가 '보습감'을 이야기했다")

### 5-2. 사진 배치
- **공식 사진이 주인공**이다. 카드뉴스 장마다 먼저 1-1단계에서 모은 공식 사진 중 어울리는 것을 고른다.
- 공식 사진으로 표현하기 어려운 장면(예: 페르소나의 일상, 고민하는 순간)만 **AI 이미지로 보충**한다.
  - 이미지 생성 도구가 있으면 생성해서 `images/ai/`에 저장하고, 없으면 생성 프롬프트만 작성한다.
  - 프롬프트에는 공식 사진의 톤(색감, 조명, 배경)을 반영해서 공식 사진과 어색하지 않게 한다.
  - AI 이미지에는 **"AI 생성 이미지"** 표시를 붙인다. 제품 자체를 AI로 새로 그리지 않는다.
- 카드뉴스 한 세트에서 AI 이미지는 **최대 2장**까지만 쓴다.

## 6단계. 카드뉴스 (한 세트, 5~7장)

페르소나 3명을 **하나의 카드뉴스로 합친다.** 내용은 **핵심 페르소나의 이야기**를 따라 흐르고,
나머지 2명은 "이런 분들도 있어요"처럼 중간에 자연스럽게 등장한다.
**7장 중 최소 3장에는 통계 그래프나 숫자**가 들어가야 하며, 그중 대부분은 직접 집계한 리뷰 통계로 채운다.

### 기본 구성 (7장)

| 장 | 역할 | 내용 | 시각 자료 |
|---|---|---|---|
| 1 | 훅 | 핵심 페르소나의 고민을 그들의 말투로 던지는 한 문장 | 공식 무드 컷 (없으면 AI 보충) |
| 2 | 공감 | 그 고민이 왜 반복되는지 + **불만/고민 통계** | 피부 고민 비율 또는 큰 숫자 하나 |
| 3 | 확장 | "이런 분들도 같은 고민을 해요" — 페르소나 3명 소개 | `05_페르소나비중.png` |
| 4 | 해결 | 휩드가 이 고민에 답하는 방식 + 경쟁사와의 차이 | 공식 제품·텍스처 컷 + `06_경쟁사비교.png` |
| 5 | 증거 | **"리뷰 N개를 직접 읽어 봤습니다"** — 만족 키워드 통계 + 리뷰 인용 | `02_만족키워드.png` |
| 6 | 정리 | 핵심 페르소나의 "사용 전 → 사용 후" 변화 + 재구매 비율 | 공식 사용 장면 컷 |
| 7 | 마무리 | 브랜드 메시지 + 행동 유도 (CTA) | 공식 제품 컷 |

5장으로 줄일 때는 2+3장, 5+6장을 합친다. 시장 통계는 2장이나 4장에 한 줄로만 보조로 넣는다.

### 장마다 쓸 내용

```
[N장] 역할
- 메인 문구: (20자 안팎)
- 서브 문구: (1~2문장)
- 핵심 숫자: (있으면) "리뷰 N개 중 M개(○%)"
- 사진: images/official/파일명 (출처: 휩드 공식 홈페이지) 또는 images/ai/파일명 (AI 생성 이미지)
- 그래프: images/charts/파일명 (있으면)
- 레이아웃 제안: 사진·그래프·문구 배치를 한 줄로
- 기획 의도: (포트폴리오 말투, 아래 톤 가이드 참고)
- 근거: 2~4단계의 어느 발견에서 왔는지
```

## 톤 가이드

결과물에는 두 가지 목소리가 있다. 섞이지 않게 구분한다.

### ① 카드뉴스 문구 = 휩드 브랜드 톤
- 1단계에서 모은 **공식 인스타그램·상세페이지 문구**를 보고 말투를 먼저 분석한다.
  (존댓말/반말, 문장 길이, 자주 쓰는 단어, 이모지 사용 여부, 감성형인지 정보형인지)
- 분석한 말투 특징을 3줄로 문서에 적고, 카드뉴스 문구를 그 말투로 쓴다.
- 통계 숫자도 브랜드 톤으로 풀어 쓴다. (예: "40%" → "10명 중 4명이 말했어요")

### ② 기획 의도·분석 문서 = 포트폴리오 말투 (사용자 본인의 목소리)
- 사용자가 면접관에게 직접 설명하는 것처럼 **1인칭**으로 쓴다.
- 패턴: **"무엇을 봤고 → 무엇을 발견했고(숫자) → 그래서 이렇게 기획했다"**
- 예시:
  > "올리브영과 자사몰 리뷰 52개를 직접 분류해 보니, 21개(40%)에서 '세안 후 당김'이 언급됐습니다.
  > 그래서 첫 장은 제품 소개보다 이 불편함에 공감하는 문장으로 시작했습니다."
- 근거 없는 자기 자랑, 과장된 표현("완벽한", "압도적인")은 쓰지 않는다.

## 7단계. 캠페인 제안 — "내가 휩드 마케터라면"

분석을 "그래서 무엇을 하겠다"로 끝맺는 단계다. 캠페인은 **1개만** 깊게 제안한다.

**출발점** (세 가지를 모두 연결한다)
- 대상: 4단계의 **핵심 페르소나**
- 해결할 문제: 2-3단계에서 찾은 **1순위 기회**
- 무기: 3단계에서 찾은 **휩드만의 차별점**

**제안서 템플릿**

```
### 캠페인명: (짧고 기억에 남게, 휩드 브랜드 톤)

1. 한 줄 요약
   "○○한 [핵심 페르소나]에게, △△을 통해 □□을 느끼게 한다."

2. 왜 이 캠페인인가 (근거)
   - 리뷰 통계: "리뷰 N개 중 M개(○%)가 ..."
   - 불만에서 찾은 기회: ...
   - 경쟁사와의 차이: ...

3. 타깃
   - 메인: 핵심 페르소나
   - 서브: 나머지 페르소나 중 함께 반응할 1명

4. 핵심 메시지 (브랜드 톤, 1문장)

5. 실행 계획
   | 단계 | 기간 | 채널 | 콘텐츠 | 목적 |
   |---|---|---|---|---|
   | 관심 끌기 | 1주차 | 인스타 릴스 등 | ... | 인지 |
   | 참여 유도 | 2~3주차 | ... | ... | 참여 |
   | 구매·후기 | 4주차 | 올리브영, 자사몰 등 | ... | 전환 |
   - 6단계 카드뉴스가 이 캠페인의 어느 단계에 쓰이는지 명시한다.

6. 성과 측정 (KPI)
   | 지표 | 왜 이 지표인가 | 목표 방향 |
   |---|---|---|
   | 콘텐츠 저장 수 / 공유 수 | 핵심 페르소나가 정보를 저장해 두는 성향 | 증가 |
   | 리뷰 속 1순위 불만 키워드 비중 | 기회를 실제로 풀었는지 확인 | 감소 |
   | 리뷰 속 차별점 키워드 비중 | 메시지가 전달됐는지 확인 | 증가 |
   | 재구매 언급 비율 | 장기 고객으로 이어지는지 확인 | 증가 |
   - 구체적인 목표 수치는 근거가 없으면 쓰지 않고 "증가/감소" 방향만 쓴다.
   - 2단계 리뷰 통계를 **캠페인 전 기준값**으로 삼아, 같은 방식으로 다시 집계하면 비교할 수 있다고 설명한다.

7. 예상 리스크와 대응
   - 리스크 1~2개와 각각의 대응 방법

8. 기획 의도 (포트폴리오 말투, 3~4문장)
```

**규칙**
- 예산, 매출 같은 내부 수치는 알 수 없으므로 만들지 않는다.
- 실제 휩드가 이미 진행한 캠페인과 겹치는지 1단계 자료에서 확인하고, 겹치면 무엇이 다른지 적는다.
- 아이디어는 화려함보다 **분석과의 연결**이 분명해야 한다. 모든 항목이 2~4단계의 근거로 거슬러 올라가야 한다.

## 최종 결과물

모든 파일은 `휩드_페르소나분석_YYYYMMDD/` 폴더 하나에 담는다.

```
휩드_페르소나분석_YYYYMMDD/
├── 휩드_페르소나분석.md      ← 분석 문서 (노션·워드에 붙여넣기용)
├── 휩드_카드뉴스.md          ← 카드뉴스 문구 + 장별 사진·그래프 지정
├── data/
│   └── reviews.csv           ← 직접 집계한 리뷰 원자료
└── images/
    ├── official/             ← 휩드 공식 사진 (포트폴리오용, 크레딧 표기)
    ├── ai/                   ← AI 생성 보충 이미지
    └── charts/               ← 통계 그래프 PNG
```

**분석 문서 순서**
1. 분석 개요 (목적, 조사 기간, 자료 출처, 리뷰 모수)
2. 리뷰 직접 집계 결과 (그래프 + 해석 + 리뷰 인용)
3. 불만 리뷰에서 찾은 기회 (기회 표 + 1순위 결론)
4. 경쟁사 비교 (비교표 + 그래프) 및 시장 통계
5. 페르소나 3명 (핵심 페르소나 먼저, 대표 이미지 포함)
6. 카드뉴스 기획안 (장별 문구, 사진, 그래프, 기획 의도)
7. 캠페인 제안: 내가 휩드 마케터라면 (실행 계획 + KPI)
8. 참고 자료 (출처 URL 목록, 이미지 출처 목록, 분석의 한계)

문서 안의 사진과 그래프는 상대 경로로 넣는다. 예: `![별점 분포](images/charts/01_별점분포.png)`

작업이 끝나면 채팅에서는 **핵심 페르소나 한 줄 정의, 가장 인상적인 리뷰 통계 1개, 1순위 기회, 캠페인명과 한 줄 요약, 결과 폴더 위치**만 짧게 알려 준다.
