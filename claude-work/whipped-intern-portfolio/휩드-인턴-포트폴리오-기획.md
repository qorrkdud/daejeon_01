# 휩드(WHIPPED) 인턴 지원 포트폴리오 기획

2026-11-05 Claude 세션 "휩드 인턴 지원 포트폴리오"의 결과를 정리했어요. 공고 분석, 포트폴리오 구성안, 팩클렌저 숏폼 3종 콘티가 들어 있어요.

> 공개 저장소라서 지원자 개인 정보(전공, 자격증, 수상 이력)와 채용 공고 PDF는 넣지 않았어요.

## 1. 공고 분석: 휩드가 원하는 사람

| 공고 문구 | 실제로 보려는 것 | 포트폴리오에서 보여줄 방법 |
| --- | --- | --- |
| 기획, 촬영, 편집, 제작까지 직접 | 혼자 소재 하나를 끝까지 완성하는 사람 | 완성된 영상·이미지 링크 (필수 제출 조건) |
| 제품 USP로 구매 욕구 설계 | 기능을 사고 싶은 이유로 바꾸는 능력 | USP를 훅·카피로 바꾸는 과정 |
| 메타, 틱톡, 구글, 네이버 소재 | 매체마다 다르게 만들 줄 아는지 | 같은 메시지를 매체별로 바꾼 버전 |
| 소재 A/B 테스트 | 감이 아닌 데이터로 고치는 습관 | 가설, 변수, 지표, 결과 |
| 실제 구매 전환 경험 | 숫자로 검증해 본 경험 | 작게라도 직접 돌린 테스트 수치 |

핵심은 "전략을 잘 짜는 사람"보다 "광고 소재를 빨리 만들고 숫자로 검증하는 사람"이에요. 업무가 전부 광고 콘텐츠라서 포트폴리오도 제작물이 60% 이상이어야 해요.

## 2. 휩드에 대해 알아둘 것

- 대표 제품 팩클렌저는 나이아신아마이드, 세라마이드, 히알루론산 등 스킨케어 성분이 50% 이상이고, "세안 + 팩" 겸용이 가장 강한 USP예요. (출처: magazine.hankyung.com)
- 대표 인터뷰에 따르면 카카오 선물하기가 주력 채널이고, 인스타그램 광고는 ASMR 같은 '보고 싶은 콘텐츠'로 만들어요. (출처: magazine.hankyung.com)
- 공식몰에는 팩클렌저 6종 리뉴얼, 비건 선크림, 휘핑 버블 세럼, 토핑 바디버터가 있어요. (출처: whipped.co.kr)
- 이너시아와 함께 만든 여성청결제가 10월 올영픽에 선정됐고(출처: cmn.co.kr), 10월 16일부터 일본 판매를 시작했어요(출처: crea.bunshun.jp).

## 3. 포트폴리오 방향

**컨셉 한 줄:** "성분을 아는 사람이 만드는, 3초 안에 사고 싶어지는 휩드 광고 소재"

**구성안 (10~12장, 제작 중심)**

1. 표지 + 링크 모음: 영상과 이미지 링크를 첫 장에 배치 (필수 조건이라 맨 앞에)
2. About (1장): "제형과 성분을 이해하는 콘텐츠 마케터"로 짧게 정리
3. 휩드 USP 분석 (1장): 세안+팩 겸용, 휘핑크림 제형, 베이커리 레시피 네이밍, 선물 경험. 각 USP를 고객 언어 한 줄로 번역
4. 광고 소재 A: 팩클렌저 숏폼 3종 (핵심). 같은 제품을 훅만 바꿔서 제작
5. 광고 소재 B: 매체별 버전. Meta 피드(4:5), 릴스·틱톡(9:16), 네이버 GFA 배너, 유튜브 쇼츠
6. 이미지 소재: 상세페이지 첫 화면 또는 배너 3종 (신제품 하나 포함)
7. 기존 제작물: @weekly.beauty.recipe 카드뉴스 중 반응 좋았던 것 2~3개
8. A/B 테스트 설계 + 미니 테스트 결과: 가설, 변수(훅·썸네일·카피), 지표(3초 재생률, CTR, CPC)
9. AI 툴 활용 과정: 기획, 카피, 자막, 썸네일을 AI로 빠르게 만든 과정
10. 트렌드 포맷 실험: 최근 숏폼 포맷을 휩드에 적용한 아이디어 2~3개
11. 6개월 로드맵 (1장)

## 4. 약점 보완 전략

- **성과 수치가 없는 문제:** 직접 만든 소재 2~3개를 Meta에 1~3만 원 정도로 돌려 CTR, 3초 재생률, CPC 같은 진짜 숫자를 만들어요. 예산이 부담되면 내 계정에 릴스를 2~3가지 버전으로 올려 조회수, 저장, 완주율을 비교해요. 수치를 지어내는 건 절대 안 돼요.
- **툴 문제:** 포트폴리오 영상 자체를 CapCut으로 만들고 "CapCut으로 제작"이라고 표기해요. 이미지는 Canva나 미리캔버스로 만들고 사용한 툴을 솔직하게 적어요.
- **전략 비중 줄이기:** 페르소나, 시장 분석 장표는 1장 이하로 줄이고 제작물 장표를 늘려요.

## 5. 팩클렌저 숏폼 3종: 훅만 바꾼 A/B 세트

**설계 원칙:** 3~15초 본문과 CTA는 세 편 모두 똑같이 두고 **0~3초 훅만** 바꿔요. 그래야 지표 차이를 "훅 때문"이라고 말할 수 있어요.

- 포맷: 9:16, 15~18초, 무음으로 봐도 이해되게 자막 필수
- 제작: CapCut
- 준비물: 팩클렌저 1개, 흰 세면대나 타일 배경, 자연광, 스마트폰

### 훅 1: 제형 ASMR (가설: 보고 싶은 질감이 3초 재생률을 올린다)

| 시간 | 화면 | 자막 | 소리 |
| --- | --- | --- | --- |
| 0~1초 | 펌프나 튜브에서 휘핑 제형이 천천히 나오는 극접사 | (없음) | 짜는 소리 ASMR |
| 1~3초 | 손가락으로 제형을 꾹 눌렀다 떼서 쫀득하게 늘어나는 모습 | **이게 클렌저라고요?** | 쫀득한 소리 |
| 3~7초 | 손바닥에서 거품을 굴리고, 얼굴에 올려 문지름 | 휘핑크림 제형 그대로 얼굴에 | 거품 소리 |
| 7~11초 | 헹군 뒤 볼을 손등으로 톡톡, 물광 클로즈업 | 세안했는데 팩한 것처럼 촉촉 | 물소리 |
| 11~15초 | 제품 정면 + 성분 텍스트 | 나이아신아마이드 · 세라마이드 · 히알루론산 | 경쾌한 BGM |
| 15~17초 | 제품 들고 엔딩 | **세안 + 팩, 한 번에** / 프로필 링크 | |

### 훅 2: 문제 해결 (가설: 귀찮음을 건드리면 CTR이 올라간다)

| 시간 | 화면 | 자막 |
| --- | --- | --- |
| 0~1.5초 | 세면대에 클렌저, 팩, 토너가 줄지어 있음 → 손으로 한 번에 치움 | **세안하고 팩까지 하기 귀찮은 사람?** |
| 1.5~3초 | 팩클렌저 하나만 남김, 줌인 | 이거 하나면 끝나요 |
| 3~15초 | 훅 1의 3~15초와 동일 | (동일) |
| 15~17초 | 엔딩 동일 | **세안 + 팩, 1분이면 끝** |

### 훅 3: 선물 (가설: 선물 맥락이 저장과 공유를 늘린다)

| 시간 | 화면 | 자막 |
| --- | --- | --- |
| 0~1.5초 | 카톡 선물 알림이 뜬 폰 화면 (본인 폰으로 연출) | **친구한테 이거 선물 받았는데** |
| 1.5~3초 | 상자 열기 → 제품을 꺼내는 언박싱 | 솔직히 기대 안 했거든요 |
| 3~15초 | 훅 1의 3~15초와 동일 | (동일) |
| 15~17초 | 엔딩 | **받는 사람이 진짜 쓰는 선물** |

"카톡 선물하기 1위" 같은 문구는 휩드 공식 자료에서 확인된 표현일 때만 써요.

### 촬영 순서

1. 공통 본문(3~15초)을 먼저 한 번만 찍기: 거품, 세안, 물광, 제품 정면
2. 훅 컷 3개를 따로 찍기: 제형 접사, 세면대 치우기, 언박싱
3. 엔딩 컷: 제품 들고 3테이크
4. CapCut에서 본문을 템플릿으로 저장하고 훅만 갈아 끼워 3편 내보내기

제형 클로즈업은 역광이나 측광일 때 휘핑 결이 살아요. 0.5배속으로 찍어서 나중에 속도를 조절하면 ASMR 느낌이 나요.

## 6. 테스트 설계 (포트폴리오 A/B 장표 초안)

| 항목 | 내용 |
| --- | --- |
| 가설 | 제형 ASMR 훅이 3초 재생률이 가장 높고, 문제 해결 훅이 CTR이 가장 높을 것 |
| 변수 | 0~3초 훅 1개만 (본문, CTA, BGM, 길이는 고정) |
| 지표 | 3초 재생률(훅 강도), CTR(구매 의향), CPC(효율), 완주율 |
| 방법 A | Meta 광고 소재 3개 × 각 1만 원, 같은 타겟과 같은 기간 |
| 방법 B (무예산) | 본인 계정 릴스 3편을 같은 요일·시간대에 올리고 조회수, 저장, 완주율 비교 |
| 결과 기록 | 실제 수치만, 1위 소재와 그 이유, 다음 수정안 1줄 |

수치가 기대와 반대로 나와도 그대로 써요. "가설이 틀렸고, 그래서 이렇게 고쳤다"는 흐름이 공고의 "A/B 테스트로 고도화"에 가장 잘 맞아요.
