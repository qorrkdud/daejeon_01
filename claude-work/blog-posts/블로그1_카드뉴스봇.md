# [K-뉴딜 아카데미] AX 부트캠프 - 코딩 처음인 뷰티 전공자가 AI로 '인스타 카드뉴스 반자동 제작 봇' 만든 기록

안녕하세요! 오늘은 AX 부트캠프에서 진행한 **인스타그램 카드뉴스 반자동 제작 봇(cardnews-bot)** 프로젝트를 정리해 보려고 해요.

저는 뷰티를 전공했고 뷰티 기획·마케팅 직무를 준비하고 있어요. 코딩은 이번이 **정말 처음**이었어요. 그런데 이번 실습에서 **Claude Code**라는 AI 코딩 도구와 함께, 매일 아침 뷰티 뉴스를 모으고 → 오늘 쓸 소재를 골라 주고 → 카드뉴스 이미지와 릴스 영상까지 뽑아 주는 프로그램을 만들었어요. 그 과정을 순서대로 적어 볼게요.

## 1. 왜 카드뉴스 '봇'이 필요했을까?

제가 운영하려는 인스타 계정은 **@weekly.beauty.recipe**예요. 콘셉트는 **"세안 같은 뷰티 루틴과 올리브영 제품 사용법을 요리 레시피처럼 쉽게 알려 주는 계정"**이고, 타깃은 **20~30대 뷰티 초보**예요.

문제는 카드뉴스를 꾸준히 올리려면 매일 해야 하는 일이 생각보다 많다는 거였어요.

- 뷰티 뉴스 사이트를 돌아다니며 신상·트렌드 찾기
- 그중에서 우리 계정에 맞는 소재 고르기
- 기사 내용을 내 말로 다시 쓰기
- 6장짜리 카드 디자인하고 캡션 쓰기

이걸 매일 손으로 하면 금방 지치겠더라고요. 그래서 **반복되는 일은 프로그램이 하고, 고르고 확인하는 일은 내가 하는** "반자동" 구조를 만들기로 했어요.

---

## 2. 폴더 구조를 '식당'에 비유해서 이해하기

코딩이 처음이라 폴더 구조부터 막막했는데, AI에게 **"식당에 비유해서 설명해 줘"**라고 부탁하니까 한 번에 이해됐어요. 이 방법 진짜 추천해요!

| 폴더 | 식당에서는 | 이 프로젝트에서는 |
|---|---|---|
| **sources** | 식재료 창고 | 모아 온 기사·보도자료 원본 |
| **candidates** | 손질대 | 카드뉴스 후보 아이디어 |
| **picks** | 오늘의 메뉴판 | 오늘 실제로 만들 소재 |
| **templates** | 레시피 북 | 카드 디자인 틀과 프로그램 |
| **assets** | 양념·그릇 | 제품 사진, 폰트, 이미지 |
| **output** | 완성 요리 | 완성된 카드 이미지·영상 |

흐름은 **sources → candidates → picks → (templates + assets) → output** 순서예요.
그리고 중요한 규칙 하나! **"오늘 뭘 내놓을지 고르는 것"과 "최종 맛보기"는 사장님(나)이 한다**는 거예요. AI가 다 해 주는 게 아니라, 판단은 사람이 하도록 역할을 나눴어요.

또 **CLAUDE.md**라는 파일을 만들어서 "우리 가게 운영 수칙"을 적어 뒀어요. 예를 들면 **기사 문장을 그대로 베끼지 않기, 출처 꼭 표기하기, 없는 사실 지어내지 않기, 카드별 글자 수 제한** 같은 규칙이에요. AI는 작업할 때마다 이 파일을 먼저 읽고 그대로 따라요.

## 3. 매일 아침 뉴스 자동 수집: morning.bat

먼저 **매일 새 소식이 올라오는 믿을 만한 뷰티 사이트 15곳**을 조사했어요. 장업신문, 코스모닝, 코스인코리아 같은 국내 업계지부터 Allure, Vogue Beauty, WWD Beauty 같은 해외 매체까지요. 그중 **RSS가 실제로 동작하는 12곳**을 골라 목록으로 저장했어요.

그다음 만든 게 **morning.bat** 파일이에요. 아침에 이 파일을 **더블클릭만 하면** 이렇게 돌아가요.

1. RSS 12곳에서 **최근 24시간 글**을 모아요. 한 곳이 실패해도 나머지는 계속 진행해요.
2. 제목·요약·링크·출처를 **candidates** 폴더에 저장해요.
3. CLAUDE.md에 적은 **선별 기준 5가지로 점수를 매겨** 상위 5개를 **picks**에 저장해요.
4. 이미 추천한 기사는 **used.txt**에 적어서 다음 날 다시 나오지 않게 해요.

첫 실행 결과는 **12곳 중 11곳 성공, 후보 80개**였어요. 파이썬 기본 기능만 써서 따로 설치한 도구도 없었어요.

> 📷 **[사진 3 – 실습 화면 캡처]** morning.bat 실행 후 추천 5개가 뜬 화면

## 4. 자동 추천이 틀릴 때, 규칙을 고쳐 나가기

여기서 배운 게 정말 많았어요. **자동 추천이 항상 맞지는 않더라고요.**

다음 날 64개 후보 중 자동 상위 5개를 보니, 1위가 **전날 만든 크림 미스트와 같은 제품**이었어요. 다른 매체가 같은 제품 기사를 써서 링크 비교만으로는 중복을 못 걸러낸 거예요. 나머지도 실적 뉴스, 1년 뒤 출시 향수처럼 우리 계정과 거리가 먼 소식이 많았어요.

그래서 규칙을 하나 추가했어요.
**"최근 7일 안에 고른 소재와 제목이 많이 겹치면 링크가 달라도 제외한다."**

이 규칙을 넣고 다시 채점하니까, 원래 13점으로 순위 밖이던 **Vogue의 '한국 각질 제거 제품' 기사가 18점으로 1위**가 됐어요. 각질 관리는 뷰티 초보가 가장 헷갈려하는 루틴이라 "고민 → 레시피" 구조에 딱 맞는 소재였어요.

**자동화는 한 번 만들고 끝이 아니라, 결과를 보고 규칙을 계속 다듬는 과정**이라는 걸 몸으로 느꼈어요.

## 5. 카드 6장 만들기: make.bat

소재를 고르면 **make.bat**으로 카드를 만들어요. 과정은 4단계예요.

1. **[1/4] 후보 고르기** – 오늘 picks 5개 중 번호 선택
2. **[2/4] cards.json 준비** – 카드 문구 확인, 글자 수 규칙 검사
3. **[3/4] 이미지 6장 만들기** – 디자인 방식 선택
4. **[4/4] 폴더 열기** – 완성본 확인

디자인은 계정 톤에 맞춰 **메인 색 테라코타(#C9735A), 피치, 버터, 크림 배경, 진갈색 글자**로 정했어요. 카드마다 **표지 / 고민 체크 / 재료 / 원리 / 비교 / 정리** 같은 **layout(카드 종류)**을 지정할 수 있게 만들었고, 제품 사진이 들어가면 **사진 출처가 자동으로 붙어요.**

처음엔 글만 가득한 카드였는데, "제품 설명만 하지 말고 **평소 고민을 먼저 꺼내고, 이 제품을 이렇게 쓰세요**로 이어지게 해 줘"라고 방향을 바꿨어요. 그랬더니 훨씬 저장하고 싶은 카드가 됐어요.

> 📷 **[사진 4 – 결과물 캡처]** 완성된 '세안 레시피' 카드뉴스 6장

## 6. AI가 쓴 글도 반드시 팩트체크!

카드 문구는 AI가 기사를 읽고 새로 써 주는데, **검수를 해 보니 사실 오류가 2개** 나왔어요.

- 기사에 없던 **"올리브영이 아니라"**라는 표현이 들어가 있었고
- **"11월 5일 내놓은"**이라고 썼는데, 그날은 출시일이 아니라 **발표일**이었어요.

이걸 보고 **"AI가 만든 결과물의 최종 책임은 나한테 있다"**는 걸 확실히 느꼈어요. 그래서 picks 파일에는 후보마다 **"사실 확인이 필요한 부분"**이 같이 적히도록 했어요.

## 7. 카드뉴스를 릴스 영상으로

인스타는 릴스 노출이 중요하니까, 카드 6장을 **1080×1920 세로 영상(mp4)**으로도 만들었어요. 카드 한 장당 3초, 부드러운 전환 효과를 넣었고, 영상 처리를 위해 **imageio-ffmpeg**를 설치했어요. 설치 전에 AI가 "무엇을, 왜 설치하는지, 지우는 방법은 뭔지"를 먼저 설명해 줘서 안심하고 진행할 수 있었어요.

실제 사람이 세수하는 것처럼 움직이는 영상도 만들고 싶어서 **Kling AI** 같은 이미지→영상 생성 서비스도 시도해 봤어요. PC 편집만으로는 사진을 확대·이동하는 정도밖에 안 되고, 손과 얼굴이 진짜로 움직이려면 AI 영상 생성이 필요하다는 것도 배웠어요.
