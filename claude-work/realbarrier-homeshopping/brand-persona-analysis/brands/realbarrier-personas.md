# 리얼베리어 고객 페르소나 (50대 이상)

`brand-persona-analysis` 스킬 절차를 따랐다. 사용자 요청에 따라 50대 이상으로 설정했고, 연령 근거가 부족한 부분은 "(추정)"으로 표시했다.

## 1. 분석 개요

- **수집 리뷰**: 59개 (컬리 '[리얼베리어] 익스트림 크림 65ml + 25ml' 상품 후기 전체)
- **수집 기간**: 2025.01 ~ 2026.11 (리뷰 작성일 기준), 수집일 2026.11.11
- **연령 표시 리뷰**: 15개 (50대 2, 40대 7, 30대 6). 나머지 44개는 연령 미표시
- **건너뛴 사이트**: 글로우픽(웹에서 리뷰 미표시, 앱 전용), 언파(웹에서 리뷰 1건씩만 표시), 리얼베리어 공식 몰 리뷰 게시판(404·504 오류), 화해(앱 전용)
- **분류 방법**: 리뷰마다 피부 고민·구매 동기·사용 상황·재구매 의사·불만을 뽑아 비슷한 리뷰끼리 묶었다. 연령은 태그와 가족 구매 단서, 홈쇼핑 구매 고객 구성(50·60대 60% 이상, 한국TV홈쇼핑협회)을 함께 참고했다.
- **한계**: 50대 태그 리뷰는 2개뿐이다. 50대 이상 설정은 홈쇼핑 고객층 자료를 바탕으로 한 추정이 섞여 있다. 충성 그룹은 2개만 나와 억지로 3개로 나누지 않았다.

## 4. 경쟁 브랜드 비교
- **에스트라 아토베리어365**: 이탈 리뷰 1개에서 "아토***365가 훨씬 나은 거 같네요"로 언급. 무거움·끈적임이 이탈 이유.
- **일리윤 세라마이드 아토**: 수집한 리뷰에 언급 없음.

## 5. 핵심 인사이트
1. 리뷰의 71%가 "항상·꾸준히·겨울 필수" → 오래 쓰는 재구매 고객이 중심 → **4통 대용량** 구성의 근거.
2. 20%는 가족 몫·할인 구매 → **가족 세트**와 정확한 사은품 안내가 필요.
3. 불만은 '무거움·튜브·끈적임'에 몰려 있음 → 신제품의 **펌프 용기와 가벼운 마무리**가 이 불만을 직접 해결.
4. 50대 태그 리뷰는 '건성·건조함' → 50대 속건조 메시지와 일치. 다만 표본 2개라 시험 방송 데이터로 확인 필요.
